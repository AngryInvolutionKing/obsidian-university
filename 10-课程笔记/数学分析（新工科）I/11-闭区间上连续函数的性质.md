# 闭区间上连续函数的性质

- 关联课程主页：[[数学分析（新工科）I]]

## 本讲速览

本页按两张标题为“二、最值性”的连续板书照片，收录定理 3.4.2：闭区间上的连续函数能够取得最小值与最大值。板书调用有界性，利用下确界选取点列，再由 BW 定理取得收敛子列，用连续性把输入的收敛转化为函数值的收敛，最后通过夹逼确定最小值。

续图已补齐子列的夹逼不等式、函数值极限为 $\alpha$，以及由连续性得到 $f(\xi)=\alpha$ 的收尾。最大值证明、有界性的前置证明、阶段解释与考场书写版，在正文中分别标为补充。

另收录“三、零点存在定理”的两张证明板书及一张收尾与例题续图。定理 3.4.3 通过保持端点异号构造闭区间套，再用连续性和极限保序性确定零点；存在内点零点的最终结论已由续图核对。完整分支规则、内点性的详细解释、误差估计与考场版在正文中单独标为补充。

续图还给出例题 Ex3.4.3：闭区间上的连续自映射有不动点，要求自行证明。题干与不动点称谓已核对，完整补充解答单独保存，采用作差函数和端点分类应用零点存在定理。

“四、介值性”的三张板书给出定理 3.4.4 及值域为最小值、最大值所确定闭区间的推论。正文保留利用零点存在定理的板书主线，并补充上确界构造、区间套证明、最值点左右顺序的处理与考场版。

“五、一致连续”的板书已给出定义 3.4.1：给定输出误差后，对整个区间的所有点对使用同一个输入距离标准。两张续图进一步反解倒数函数的连续性要求，标出最大允许半径，并用下确界说明统一选取的条件。最大性的验证、下确界为零时的收尾、量词比较与近点对证明标为补充；后续编号定理尚未出现。

## 复习清单

- [ ] 能区分“值域有下确界”和“函数取得最小值”。
- [ ] 能从下确界的定义说明为什么对每个 $n$ 都能选到 $\alpha\le f(x_n)<\alpha+1/n$。
- [ ] 能分别说明区间有界、区间闭、函数连续在证明中的用途。
- [ ] 能说明为什么取收敛子列，并用 $1/n_k\to0$ 完成夹逼。
- [ ] 能写出最大值证明，并独立完成考场书写版。
- [ ] 能按中点函数值的三种情况处理二分，并说明每一步为什么保留相应半区间。
- [ ] 能由 $[a_1,b_1]=[a,b]$ 写出 $b_n-a_n=(b-a)/2^{n-1}$。
- [ ] 能说明为什么取极限后使用非严格不等式，以及如何证明零点位于 $(a,b)$。
- [ ] 能区分零点存在、零点唯一与二分法的误差估计。
- [ ] 能将不动点问题改写为作差函数的零点问题，并分别处理端点与内点情形。
- [ ] 能用最值定理与零点存在定理证明介值性，且不假设最小值点在最大值点左侧。
- [ ] 能解释三种证明的核心构造，并用两个包含关系说明值域恰为 $[m,M]$。
- [ ] 能写出逐点连续与一致连续的量词顺序，说明统一的 $\delta$ 可以依赖什么。
- [ ] 能证明一致连续推出连续，并用固定输出差距的近点对说明倒数函数在 $(0,1)$ 上不一致连续。
- [ ] 能反解倒数函数的误差不等式，证明允许半径的最大性，并区分“某种选法的下确界为零”与“最大半径的下确界为零”。
