# 闭区间上连续函数的性质

- 关联课程主页：[[数学分析（新工科）I]]

## 本讲速览

本页按两张标题为“二、最值性”的连续板书照片，收录定理 3.4.2：闭区间上的连续函数能够取得最小值与最大值。板书调用有界性，利用下确界选取点列，再由 BW 定理取得收敛子列，用连续性把输入的收敛转化为函数值的收敛，最后通过夹逼确定最小值。

续图已补齐子列的夹逼不等式、函数值极限为 $\alpha$，以及由连续性得到 $f(\xi)=\alpha$ 的收尾。最大值证明、有界性的前置证明、阶段解释与考场书写版，在正文中分别标为补充。

另收录“三、零点存在定理”的两张证明板书及一张收尾与例题续图。定理 3.4.3 通过保持端点异号构造闭区间套，再用连续性和极限保序性确定零点；存在内点零点的最终结论已由续图核对。完整分支规则、内点性的详细解释、误差估计与考场版在正文中单独标为补充。

续图还给出例题 Ex3.4.3：闭区间上的连续自映射有不动点，要求自行证明。题干与不动点称谓已核对，完整补充解答单独保存，采用作差函数和端点分类应用零点存在定理。

“四、介值性”的三张板书给出定理 3.4.4 及值域为最小值、最大值所确定闭区间的推论。正文保留利用零点存在定理的板书主线，并补充上确界构造、区间套证明、最值点左右顺序的处理与考场版。

“五、一致连续”的板书已给出定义 3.4.1，以及倒数函数的反解、最大允许半径标注和正下确界条件。续图给出 $1/x$ 在 $[a,1]$ 上的统一估计，并进入“2. 一致连续的充要条件”：定理 3.4.5 的点列判别陈述与双向证明均已核对，收尾续图明确了正向选取 $\delta$ 与 $N$ 的关系，并补齐反向的反证法。最大性验证、下确界为零时的收尾、极限衔接与近点对证明标为补充。

应用续图进一步说明点列判别的使用方向，并用 $1/n$、$1/(2n)$ 证明倒数函数不一致连续。同图 Ex3.4.7 要求比较平方函数在有限区间与非负半直线上的一致连续性，题干已核对，补充解答单独归入例题页。

“3. 闭区间上连续与一致连续等价”的两张板书给出定理 3.4.6（Cantor 定理）：反设不一致连续，用 BW 定理取第一列的收敛子列，第二列沿用相同下标，再由连续性得到输出差趋于零。正文补上对子列仍有效的固定正下界，明确最后矛盾的依据。

后续板书给出定理 3.4.7：有限开区间内的连续函数一致连续，当且仅当两端的有限单侧极限存在。充分性由补上端点值、调用 Cantor 定理得到；必要性已由续图补齐，任取趋向端点的点列，证明其函数值构成基本列并收敛，再用归结原则得到端点极限。共同极限的衔接与另一种直接估计证明标为补充。

同组续图提醒该端点判别不能照搬到无限区间，并用全实轴上的 $\sin x$ 举例；随后给出一致连续的区间可加性：$(a,b]$ 与 $[b,c)$ 上分别一致连续，可经共同接点 $b$ 拼接为 $(a,c)$ 上的一致连续。拼接证明单独标为补充。

## 复习清单

- [ ] 能区分“值域有下确界”和“函数取得最小值”。
- [ ] 能从下确界的定义说明为什么对每个 $n$ 都能选到 $\alpha\le f(x_n)<\alpha+1/n$。
- [ ] 能分别说明区间有界、区间闭、函数连续在证明中的用途。
- [ ] 能完整写出有界性定理的反证证明：无界的否定式、$|f(z_n)|>n$、BW 取子列、极限点留在区间内、收敛数列有界与 $n_k\ge k$ 的矛盾。
- [ ] 能说明为什么取收敛子列，并用 $1/n_k\to0$ 完成夹逼。
- [ ] 能写出最大值证明，并独立完成考场书写版。
- [ ] 能按中点函数值的三种情况处理二分，并说明每一步为什么保留相应半区间。
- [ ] 能由 $[a_1,b_1]=[a,b]$ 写出 $b_n-a_n=(b-a)/2^{n-1}$。
- [ ] 能说明为什么取极限后使用非严格不等式，以及如何证明零点位于 $(a,b)$。
- [ ] 能区分零点存在、零点唯一与二分法的误差估计。
- [ ] 能将不动点问题改写为作差函数的零点问题，并分别处理端点与内点情形。
- [ ] 能用最值定理与零点存在定理证明介值性，且不假设最小值点在最大值点左侧。
- [ ] 能解释三种证明的核心构造，并用两个包含关系说明值域恰为 $[m,M]$。
- [ ] 能写出逐点连续与一致连续的量词顺序，说明统一的 $\delta$ 可以依赖什么。
- [ ] 能证明一致连续推出连续，并用固定输出差距的近点对说明倒数函数在 $(0,1)$ 上不一致连续。
- [ ] 能反解倒数函数的误差不等式，证明允许半径的最大性，并区分“某种选法的下确界为零”与“最大半径的下确界为零”。
- [ ] 能在 $[a,1]$ 上用统一的分母下界选取 $\delta=a^2\varepsilon$。
- [ ] 能证明定理 3.4.5 的两个方向，并说明它只要求对应点距离趋于零，不要求两列点各自收敛。
- [ ] 能用点列判别说明倒数函数不一致连续，并完成例题 3.4.7 中平方函数的两个区间结论。
- [ ] 能证明 Cantor 定理，说明第二列为何沿用相同下标，以及固定正下界为何在取子列后仍有效。
- [ ] 能证明有限开区间的端点判别，明确端点极限必须有限，并区分“某列函数值收敛”与“端点函数极限存在”。
- [ ] 能说明任意趋向端点的点列为何产生共同的函数值极限，并用 $\sin x$ 解释有限区间条件的作用。
- [ ] 能证明一致连续的区间可加性，说明共同接点 $b$ 与 $\varepsilon/2$ 的用途。
