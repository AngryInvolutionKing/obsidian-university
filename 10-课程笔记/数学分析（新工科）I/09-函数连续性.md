# 函数连续性

- 关联课程主页：[[数学分析（新工科）I]]

## 本讲速览

本讲从函数极限进入函数连续性。已按板书收录定义 3.2.1 的点连续及其 $\varepsilon$-$\delta$ 表达、定义 3.2.2 的开区间内连续，以及例 3.2.1：用定义证明 $f(x)=1/x$ 在 $(0,1)$ 内连续。定义域条件的显式说明、$\delta$ 的选取解释和末尾收尾标为补充。

间断点分类已按板书收录第一类中的可去、跳跃间断点，以及第二类中的无穷型、振荡型间断点示例。连续性习题分别计算取整函数、指数衰减函数及有理数与无理数分段函数的连续点。

狄利克雷函数的板书证明分别在有理点、无理点构造从右侧趋近的两列点，由海涅定理证明每一点都是第二类间断点；有理点列的具体选取与左极限的论证另作补充。

新增板书给出黎曼函数的极限、连续性与周期性结论；例 3.2.8 用上、下确界证明单调函数在内点的单侧极限存在，例 3.2.9 说明其间断点至多可列。黎曼函数的证明与可列性证明未展示的部分已单独标为补充。

补充习题包括乘积连续性的反例、五个幂指函数极限，以及由 $f(x^2)=f(x)$ 和连续性证明函数为常数。第 7 题的通用结论及其证明单独归入理论页。

## 复习清单

- [ ] 能陈述点连续的定义及其 $\varepsilon$-$\delta$ 表达，说明 $f(x_0)$ 必须有定义。
- [ ] 能说明连续性定义中为什么不必排除 $x=x_0$。
- [ ] 能从“任意一点连续”推出“在开区间内连续”。
- [ ] 能说明例 3.2.1 中 $\delta$ 的两个限制分别控制分母和函数值误差。
- [ ] 能完整证明 $f(x)=1/x$ 在 $(0,1)$ 内连续，并明确 $x$ 的定义域限制。
- [ ] 能通过左右极限和函数值区分连续、可去间断、跳跃间断与第二类间断。
- [ ] 能按“定义域与候选点 → 左右极限 → 两侧比较 → 函数值”判定类型，并区分单侧极限存在与双侧极限存在。
- [ ] 能按 $x_0$ 为有理数或无理数构造两列从同侧趋近的点，证明狄利克雷函数的单侧极限不存在。
- [ ] 能用有界区间内分母有界的有理数只有有限个，证明黎曼函数在任意点的极限为 $0$，并检验其周期性。
- [ ] 能用上、下确界证明单调函数的单侧极限存在，并说明间断点只能是跳跃间断点。
- [ ] 能从每个跳跃内部选取有理数，构造单射，证明单调函数的间断点至多可列。
- [ ] 能解释取整函数的跳变为何可能在乘积中消失，并用有理、无理点列检验极限。
- [ ] 能给出乘积连续而某个因子或两个因子不连续的反例，并说明非零连续因子的作用。
- [ ] 能区分指数趋于有限数和指数无界的情况，并用重要极限计算幂指函数极限。
- [ ] 能通过反复取平方根构造趋于 $1$ 的点列，证明 $f(x^2)=f(x)$ 的连续解为常数。
