# 工程力学

## 平面力系的简化

### 四、简化结果的分析、合力矩定理

将平面力系向作用面内一点简化，有三种可能结果：**合力、合力偶和平衡**。

![[2026-09-30-简化结果的分析与合力矩定理.jpg]]

| 主矢 $F_R'$     | 主矩 $M_O$     | 简化结果    | 说明                                   |
| ------------- | ------------ | ------- | ------------------------------------ |
| $F_R' = 0$    | $M_O = 0$    | **平衡**  | 平衡力系                                 |
| $F_R' = 0$    | $M_O \neq 0$ | **合力偶** | 主矩与简化中心位置无关                          |
| $F_R' \neq 0$ | $M_O = 0$    | **合力**  | 合力作用线通过简化中心                          |
| $F_R' \neq 0$ | $M_O \neq 0$ | **合力**  | 合力作用线离简化中心距离 $d = \dfrac{M_O}{F_R'}$ |

**要点理解**

- 主矢 $F_R' = \sum F_i$ 与简化中心的选择无关；主矩 $M_O = \sum M_O(F_i)$ 一般与简化中心有关。
- $F_R' = 0,\ M_O \neq 0$：力系等效为一个合力偶，此时主矩与简化中心位置无关，即 $M_O = M$（合力偶矩）。
- $F_R' \neq 0,\ M_O \neq 0$：可进一步合成为一个合力，合力大小、方向与主矢相同，作用线到简化中心的距离为
  $$d = \frac{M_O}{F_R'}$$
  合力位于使它对简化中心之矩与 $M_O$ 转向一致的一侧。
- 只有 $F_R' = 0$ 且 $M_O = 0$ 时力系才平衡，二者缺一不可。

**合力矩定理**：平面力系的合力对作用面内任一点之矩，等于力系中各分力对该点之矩的代数和，即

$$M_O(F_R) = \sum_{i} M_O(F_i)$$

（由简化结果 $M_O = \sum M_O(F_i)$ 在最终合成为合力时直接得到。）

![[2026-09-30-合力矩定理的证明.jpg]]

**证明**（针对 $F_R' \neq 0,\ M_O \neq 0$、力系可合成为一个合力的情形）：

1. 将力系向作用面内任一点 $O$ 简化，得主矢 $F_R'$ 与主矩（合力偶矩）$M_O = \sum M_O(F_i)$；
2. 主矢与主矩可进一步合成为一个合力 $F_R$（$F_R = F_R'$），其作用线过点 $O_1$，到简化中心 $O$ 的距离为 $d = M_O / F_R$；
3. 合力 $F_R$ 对 $O$ 点之矩：
   $$M_O(F_R) = F_R \cdot d = M_O$$
4. 而合力偶矩 $M_O = \sum M_O(F_i)$，代入即得
   $$M_O(F_R) = \sum M_O(F_i)$$

**分量形式**（课件绿框，实际计算常用）：

$$F_R \cdot d = M_O(F_R) = \sum M_O(F_i) = \sum M_O(F_{xi}) + \sum M_O(F_{yi})$$

即把每个力先沿坐标轴分解为 $F_{xi},\ F_{yi}$，分别求它们对 $O$ 之矩再求和，结果与合力对 $O$ 之矩相同——求矩时"先分解、再求矩、后求和"往往比直接算力臂更方便。

**作业演练**：[[作业1-平面力系的合力（向O简化）]]——含力偶的平面一般力系向 $O$ 简化，求主矢、主矩并进一步合成合力、定位作用线（用上表"先分解、再求矩、后求和"）。

### 例 4-1（教材 P67）：三角形分布载荷的合力

![[2026-09-30-例4-1-三角形分布载荷.jpg]]

**题目**：梁 AB 受三角形分布载荷 $q_x$，求合力的大小及作用线位置。

**图示要点**：梁长 $l$，A 端固定铰支、B 端滚动支座；以 A 为原点、$x$ 轴沿梁轴线、$y$ 轴竖直向上；载荷集度从 A 端的 0 线性增大到 B 端的最大值 $q$，即

$$q_x = \frac{q}{l} x$$

合力 $F$ 竖直向下，作用线过 C 点，C 到 A 的距离记为 $x_C$。

**解**：

- 合力大小（等于载荷图面积）：
  $$F = \int_0^l q_x \, dx = \int_0^l \frac{q}{l} x \, dx = \frac{ql}{2}$$
- 作用线位置（合力矩定理，对 A 取矩：合力之矩 = 各微段载荷之矩的和）：
  $$F \cdot x_C = \int_0^l x \, q_x \, dx = \int_0^l \frac{q}{l} x^2 \, dx = \frac{ql^2}{3}$$
  $$x_C = \frac{ql^2/3}{ql/2} = \frac{2}{3} l$$
- **结论**：合力大小等于三角形分布载荷图的面积 $\frac{ql}{2}$，作用线通过三角形的形心，即距 A 端 $\frac{2}{3}l$（距 B 端 $\frac{1}{3}l$）处。此结论可推广：任意分布载荷的合力 = 载荷图面积，作用线过载荷图形心。

### 五、平面一般力系的平衡条件和平衡方程

![[2026-09-30-平衡条件与平衡方程.jpg]]

**平衡条件**：力系的主矢和力系对于任一点的主矩都等于 0：

$$F_R' = 0,\quad M_O = 0$$

（即第四节分类表的第一行：平衡 ⇔ $F_R' = 0$ 与 $M_O = 0$ 同时成立，二者缺一不可。）

**平衡方程（基本形式，"二投影一矩"）**：

$$\begin{cases} \sum F_x = 0 \\ \sum F_y = 0 \\ \sum M_O(F) = 0 \end{cases}$$

- 前两个方程：各力在两坐标轴上投影的代数和分别为 0，保证 $F_R' = 0$；
- 第三个方程：各力对作用面内任一点 $O$ 之矩的代数和为 0，保证 $M_O = 0$；
- 共 3 个独立标量方程 ⇒ 最多求解 3 个未知量（典型为约束反力）。

**其它等价形式：二矩式与三矩式**

![[2026-09-30-平衡方程的二矩式与三矩式.jpg]]

二矩式：

$$\begin{cases} \sum F_x = 0 \quad (\text{或 } \sum F_y = 0) \\ \sum M_A = 0 \\ \sum M_B = 0 \end{cases}$$

- 使用条件：$A、B$ 两点的连线不能与 $x$ 轴（或 $y$ 轴，视选用哪个投影方程而定）垂直。
- 道理：若 $\sum M_A = \sum M_B = 0$，则合力（若存在）作用线必同时过 $A、B$，即沿 $AB$ 连线（课件图中 $F_R$ 沿 $AB$ 线）；此时只要 $AB$ 不垂直于 $x$ 轴，沿 $AB$ 的非零合力在 $x$ 轴上投影必不为 0，故 $\sum F_x = 0$ 就排除了合力存在的可能，力系必平衡。若 $AB \perp x$ 轴，则沿 $AB$ 的合力投影恰为 0，三个方程无法排除合力，故不适用。

三矩式：

$$\begin{cases} \sum M_A = 0 \\ \sum M_B = 0 \\ \sum M_C = 0 \end{cases}$$

- 使用条件：$A、B、C$ 三点不共线。
- 道理：三个矩方程要求合力作用线同时过 $A、B、C$；三点不共线时不存在一条直线能同时过三点，故合力必为 0，力系平衡。

### 应用平衡方程解平衡问题

#### 例 5：均布载荷悬臂梁固定端的约束反力

![[2026-09-30-例5-固定端约束反力.jpg]]

**题目**：如图所示结构（水平悬臂梁，左端 $A$ 为固定端），均布载荷为 $q = 10\ \text{kN/m}$，梁长 $L = 2\ \text{m}$，试求固定端 $A$ 处的约束反力。

**解**：

- 固定端（插入端）约束提供 3 个约束反力：$F_{Ax},\ F_{Ay},\ M_A$，恰与 3 个平衡方程对应；
- 均布载荷的合力 $F = qL = 20\ \text{kN}$，作用线过梁中点（距 $A$ 为 $L/2$）——直接用例 4-1 的结论；
- 列平衡方程（基本形式）：
  - $\sum F_x = 0:\quad F_{Ax} = 0$
  - $\sum F_y = 0:\quad F_{Ay} - qL = 0 \Rightarrow F_{Ay} = qL = 20\ \text{kN}$（向上）
  - $\sum M_A = 0:\quad M_A - qL \cdot \dfrac{L}{2} = 0 \Rightarrow M_A = \dfrac{qL^2}{2} = 20\ \text{kN·m}$（逆时针，抵抗载荷对 $A$ 的顺时针矩）
- **答案**：$F_{Ax} = 0$，$F_{Ay} = 20\ \text{kN}$（↑），$M_A = 20\ \text{kN·m}$（逆时针）。

#### 例 6（教材例 4-8，P79）：物体系——铰接折杆的固定端约束反力

![[2026-10-10-例4-8-物体系刚架固定端约束反力.jpg]]

**题目**：不计各杆自重，已知 $q、a、F=\sqrt2qa、M=2qa^2、\theta=45^\circ$，求固定端 $A$ 的约束反力及反力偶。

**读图**：

- 物体系由两根杆组成：折杆 $AEC$——竖杆高 $6a$、$A$ 端为固定端、$E$ 处为刚性角，横杆 $EC$ 长 $2a$；直杆 $CB$ 长 $a$，$C$ 处与折杆**铰接**，$B$ 端为**辊轴支座**（只提供竖直反力）。
- 竖杆上作用三角形分布载荷：$E$ 端为 0、$A$ 端为 $q$，水平压向竖杆（向右）⇒ 合力 $3qa\ (\rightarrow)$，作用线在 $A$ 上方 $2a$ 处（用例 4-1 结论：合力 = 载荷图面积、过形心）。
- $F=\sqrt2qa$ 作用在 $E$ 右侧 $a$ 处，与水平成 $\theta=45^\circ$ 斜向左下 ⇒ 分量为向左 $qa$、向下 $qa$。
- 力偶 $M=2qa^2$ 作用在杆 $CB$ 上，顺时针。

**解**

**① 判断是否静定**：杆 $CB$ 上恰有 3 个未知量（$X_C、Y_C、Y_B$），折杆 $AEC$ 上恰有 3 个未知量（$F_{Ax}、F_{Ay}、M_A$）；两个刚体各 3 个平衡方程，未知量与方程数对应 ⇒ 静定。

**② 恰当选取研究对象**：先取受力最简单的杆 $CB$，求出铰力后再取折杆 $AEC$。

**(1) 研究对象：杆 $CB$**

$$\sum F_x=0:\quad X_C=0$$

$$\sum M_C=0:\quad Y_B\cdot a-M=0\ \Rightarrow\ Y_B=\frac{2qa^2}{a}=2qa\ (\uparrow)$$

$$\sum F_y=0:\quad Y_C+Y_B=0\ \Rightarrow\ Y_C=-2qa$$

即杆 $CB$ 受铰 $C$ 的力竖直向下 $2qa$；由作用与反作用，铰 $C$ 作用在折杆上的力竖直向上 $2qa$。

**(2) 研究对象：折杆 $AEC$**（分布载荷合力 $3qa\ (\rightarrow)$ 作用于 $A$ 上方 $2a$；$F$ 的分量为向左 $qa$（高 $6a$）、向下 $qa$（距柱 $a$）；$C$ 处受竖直向上 $2qa$（距柱 $2a$））

$$\sum F_x=0:\quad F_{Ax}+3qa-qa=0\ \Rightarrow\ F_{Ax}=2qa\ (\leftarrow)$$

$$\sum F_y=0:\quad F_{Ay}-qa+2qa=0\ \Rightarrow\ F_{Ay}=-qa\ \Rightarrow\ F_{Ay}=qa\ (\downarrow)$$

$$\sum M_A=0:\quad M_A-3qa\cdot 2a+qa\cdot 6a-qa\cdot a+2qa\cdot 2a=0\ \Rightarrow\ M_A=3qa^2\ (\text{顺时针})$$

（逐项：分布载荷 $-6qa^2$ 顺；$F$ 水平分量 $+6qa^2$ 逆、竖直分量 $-qa^2$ 顺；$C$ 处反力 $+4qa^2$ 逆。）

**校核（整体）**：$\sum F_x$：$3qa-qa-2qa=0$ ✓；$\sum F_y$：$2qa-qa-qa=0$ ✓；$\sum M_A$：$-3qa^2-6qa^2+5qa^2-2qa^2+6qa^2=0$ ✓。

**结果**：$F_{Ax}=2qa\ (\leftarrow)$，$F_{Ay}=qa\ (\downarrow)$，$M_A=3qa^2$（顺时针）。

**要点**：物体系先判断静定；从"未知量恰为 3 个、受力最简单"的杆 $CB$ 入手，铰力求出后反号代回折杆；力偶直接按转向入方程、与作用位置无关。竖向净余向上（$B$ 处 $2qa\uparrow$ 大于 $F$ 的 $qa\downarrow$），故 $F_{Ay}$ 向下。
