# 02 16 位无符号计数器

**考点**：`unsigned short` 回绕、对 2^16 取模

## 题目

计数器是 16 位无符号的，初值 0。连做 q 次操作，第 i 次加上 k，每次加完输出当前值。

## 代码

```cpp
void solve02() {
    int q;
    cin >> q;

    unsigned short counter = 0;   // 16 位，0 ~ 65535

    while (q--) {
        long long k;
        cin >> k;

        k %= 65536;                                // 先砍掉整圈
        counter = (unsigned short)(counter + k);   // 截断 = 对 2^16 取模
        cout << counter << "\n";
    }
}
```

## 要点

- `unsigned short` 只有 16 位，范围 0 ~ 65535，加过头就回绕，等价于 `+ 65536` 取模。
- 先 `k %= 65536`，把整圈砍掉，省得让 `counter + k` 的结果太大。
- `counter + k` 里 `counter` 会被提升成 `int` 运算，算完再显式转回 `unsigned short` 完成截断。

## 坑

- 直接写 `counter += k;` 在 `-Wconversion` 下会告警（可能丢失数据），题目要的就是这个截断，所以显式转换写清楚。
- `short` 是 16 位是有前提的（Windows/Linux 的常见平台上都成立），标准只保证至少 16 位。
