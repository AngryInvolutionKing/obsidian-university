# 06 补码与位运算

**考点**：补码表示、有符号转无符号

## 题目

读入一个 `int` n，输出它的 32 位补码（每 4 位加一个空格），再输出把同一串 bit 当成无符号数看的值。

## 代码

```cpp
void solve06() {
    int n;
    cin >> n;

    unsigned int u = (unsigned int)n;   // 同一串 bit，换个解释

    for (int i = 31; i >= 0; --i) {
        cout << ((u >> i) & 1u);
        if (i % 4 == 0 && i != 0) cout << ' ';   // 每 4 位加空格
    }
    cout << "\n";
    cout << u << "\n";
}
```

## 要点

- 负数在内存里是补码。`(unsigned int)n` 不改 bit，只换解释方式，所以负数会变成一个很大的正数。
- `(u >> i) & 1u` 从第 31 位往第 0 位依次取一位，输出就是 32 位二进制串。
- 无符号右移是逻辑右移，高位补 0，所以取位不会出错。

## 坑

- 直接对负数右移是算术右移（高位补符号位），会得到一堆 1，必须先转 `unsigned`。
- 移位量不能等于或超过类型宽度，`i` 从 31 开始正好卡在边界内。
