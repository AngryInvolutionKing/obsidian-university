## K01 char、char*、const —— 指针类型怎么选

**考点**：`'A'` 与 `"A"` 的区别、`*` 的含义、`const` 的含义、`mystrcat` 两个参数的写法、const 与 `*` 的三种组合

### 1. char —— 存「一个」字符

```cpp
char c = 'A';     // c 里存的是字符 A（本质是个小整数 65）
char s = "A";     // ✗ 错！"A" 是字符串（后面藏着 '\0'），塞不进一个 char
```

记住：`'A'` 单引号是**一个字符**；`"A"` 双引号是**一串字符（字符串）**。

### 2. `*` —— 指针，「指向某个类型」

`*` 加在类型后面，意思是「这个变量存的不是值，而是地址」。

```cpp
char c = 'A';
char* p = &c;     // p 是指向 char 的指针，p 里存的是 c 的地址
*p = 'B';         // 通过 p 找到 c，把它改成 'B'（这叫「解引用」）
```

- `char` = 一个字符
- `char*` = 指向字符的指针

字符串就是「连续的一串字符」，所以 `char*` 常用来表示字符串——比如 `"hello"` 传进来时就要用指针接。

### 3. const —— 只读，承诺「我不改它」

`const` 修饰的东西不能修改，用来表达「这是只读的」。

```cpp
const int n = 10;
n = 20;           // ✗ 编译报错，n 不能改
```

### 4. 回到 mystrcat：char* 和 const char* 正好是两种角色

```cpp
void mystrcat(char* ptr, const char* add_char)
{
    // ...
}
```

| 参数 | 写法 | 为什么 |
| --- | --- | --- |
| `ptr` | `char*`（不加 const） | 它是**目标**，要往它指向的内存里写字符，必须能改 → 不能加 const |
| `add_char` | `const char*`（加 const） | 它是**源**，只读不改。加 const 就是向编译器和读者承诺：我不会动你 |

一句话：

- 要**修改**它指向的内容 → 用 `char*`
- 只**读取**、不改 → 用 `const char*`

### 5. const 和 `*` 的三种组合（从右往左读最清楚）

```cpp
const char* p;             // 指向的内容不能改，p 本身可以改（p 可以指向别处）
                           // 读法：p 是「指向 const char 的指针」
char* const p = ...;       // p 本身不能改，但它指向的内容可以改
                           // 读法：p 是「const 的、指向 char 的指针」
const char* const p = ...; // 两个都不能改
```

读法口诀：**从右往左读，const 贴在谁前面，谁就不能改。** 与 [[09-数组反转]]「语言解析 · const 的两种位置」是同一件事。

初学者 99% 的场景：

| 场景 | 用什么 |
| --- | --- |
| 字符串参数、字符串字面量 | `const char*` |
| 需要修改 / 遍历并写入的一串字符（比如 message 这种数组） | `char*` |

### 6. 什么时候要加 `*`？小结

| 要干什么 | 写法 |
| --- | --- |
| 存一个字符 | `char` |
| 指向 / 遍历 / 接收一串字符（字符串） | `char*` |
| 这串字符只读 | `const char*` |

**存单个字符时永远不加 `*`；处理字符串时基本都要加 `*`。**

### 易错点

- `char s = "A";` —— 编译不过。`"A"` 实际是 `'A'` + `'\0'` 两个字节，一个 char 装不下。
- `char* p = "hello";` —— 现代 C++ 里字符串字面量是只读的，用 `char*` 接会报错 / 警告，要写 `const char* p = "hello";`。真去改字面量指向的字符是未定义行为（很多环境直接崩）。
- `const char* p` 的「不能改」指**内容**，不是**指针本身**：`p++`、`p = 别的地址;` 都合法——K02 里 `add_char++` 能走，靠的就是这一点。

## K02 字符串的本体：首地址 + '\0'（传参机制）

**考点**：字符串字面量的内存布局、数组名 / 字面量退化成首地址、传值 vs 传地址、`'\0'` 哨兵、指针步长由类型决定

### 1. "storm " 在内存里长什么样

编译器会开一段连续字节，一个字符挨着一个字符放，最后必有一个 `'\0'` 收尾：

```text
地址:   0x4000  0x4001  0x4002  0x4003  0x4004  0x4005  0x4006
内容:   's'     't'     'o'     'r'     'm'     ' '     '\0'
```

### 2. 写 "storm " 时，它的「值」是首地址

在表达式里，字符串字面量（或数组名）会**退化**成指向它第一个元素的指针：

```cpp
const char* p = "storm ";   // 把 "storm " 首字符的地址（比如 0x4000）存进 p
```

p 里存的不是整串字符，而是**一个地址数字**。这跟 `int n = 5;` 里 n 存 5 是一回事——只不过这里存的是地址。

数组名也一样：

```cpp
char s[] = "storm ";
char* p = s;      // s 退化成 &s[0]，等价于 char* p = &s[0];
```

### 3. 传参时，传的就是这个地址

```cpp
mystrcat(message, "storm ");
//                 ↑ 这里传进去的其实是首地址（比如 0x4000）
```

```cpp
void mystrcat(char* ptr, const char* add_char)
{
    // ptr 里存着 message 的首地址，add_char 里存着 "storm " 的首地址
}
```

「调用时就读取了」这句话，准确说是：**调用时传进去的是首地址，函数拿到的是一个地址，不是整串内容**。整串字符还老老实实待在内存里，函数通过这个地址去「顺藤摸瓜」。

两种传参对比：

| 传什么 | 函数拿到什么 | 能改到原数据吗 |
| --- | --- | --- |
| `int` | 值的**拷贝** | 不能，改的是函数里的副本 |
| 数组 / 字符串（`char*`） | **地址**，指向的还是原来那块内存 | 能，`*ptr = ...` 直接改到 main 里的 message |

### 4. 为什么一个地址就能代表整串字符：靠 '\0'

从首地址开始，一个字符一个字符往后走；走到 `'\0'` 就知道到头了。完整的 mystrcat：

```cpp
void mystrcat(char* ptr, const char* add_char)
{
    while (*ptr != '\0')        // ① 先把 ptr 走到原串的末尾（踩在 '\0' 的位置上）
        ptr++;

    while (*add_char != '\0')   // ② 从源串首地址出发，顺着走，遇到 '\0' 停
    {
        *ptr = *add_char;       //    把当前字符搬过去
        ptr++;                  //    目标往后挪一格
        add_char++;             //    源也往后挪一格
    }
    *ptr = '\0';                // ③ 补上新的结束符
}
```

**「首地址 + '\0' 结尾」就是 C 风格字符串的全部秘密**——不需要额外告诉长度，函数自己走到 `'\0'` 就停。

注意两个指针的分工正好对应 K01：

- `ptr` 要往内存里写 → `char*`
- `add_char` 只读 → `const char*`；但 `add_char++` 完全合法——const 锁的是**指向的内容**，不是**指针本身**（K01 三种组合的第一种）。

### 5. 指针的「类型」决定每次走多远

`add_char++` 到底让地址加了几个字节？由指向的类型决定：

| 指针类型 | `p++` 后地址变化 | 原因 |
| --- | --- | --- |
| `char*` | +1 字节 | char 就是 1 字节，正好落到下一个字符 |
| `int*` | +4 字节 | 跳到下一个 int |

所以写 `add_char++`，编译器帮你算成「地址 += 1」——这也是为什么 `*add_char` 取出来的永远是「当前这个字符」。通用规律：**指针加减的单位是 sizeof(指向类型)**，与 [[09-数组反转]] 里「`p + 1` 前进的是 `sizeof(int)` 个字节」是同一条规则。

### 6. 一段小代码，亲眼看看地址

```cpp
#include <iostream>
using namespace std;

int main()
{
    const char* p = "storm ";

    cout << (void*)p        << endl;  // 首地址，比如 0x...4000
    cout << (void*)(p + 1)  << endl;  // 地址 +1，比上面大 1
    cout << *p              << endl;  // 打印 s
    cout << *(p + 1)        << endl;  // 打印 t
    cout << *(p + 2)        << endl;  // 打印 o

    return 0;
}
```

- 两个地址正好差 1，且 `*(p + 1)` 就是下一个字符 t——直接证明了「指针存地址、+1 挪一格、`*` 取当前字符」这套机制。
- 必须加 `(void*)` 强转：直接 `cout << p` 会把 `const char*` 当 C 风格字符串，输出整串 `storm `；转成 `void*` 才是打印地址值本身。

### 一句话总结

> "storm " 在内存里是「一串连续字符 + 一个 '\0'」；写它时得到的是**首地址**；函数收到的就是这个地址；靠 `*`（取一格）+ `++`（挪一格）+ `'\0'`（停下）就能走完并搬完整串字符。

## K03 char 的算术 —— 字符本质是小整数

**考点**：char 参与运算自动提升为 int、ASCII 关键值、`static_cast<char>` 收回 char、大小写转换与序号、多字符字面量 `'AB'`、char 与汉字

### 1. char 参与算术：先提升成 int，再算

char 里存的本来就是一个小整数（ASCII 码）。一旦参与 `+ - < ==` 等运算，**自动提升为 int**，算出来的也是 int——想按字符用，得用 `static_cast<char>` 收回来。

三个关键基准值（记住就能心算一切）：

| 字符 | ASCII | 备注 |
| --- | --- | --- |
| `'0'` | 48 | 数字字符从 48 连续排到 `'9'` = 57 |
| `'A'` | 65 | 大写从 65 连续排到 `'Z'` = 90 |
| `'a'` | 97 | 小写从 97 连续排到 `'z'` = 122 |

规律：**同组内字符连续，大写整个排在小写前面，大小写恒差 32**。所以 `'A' < 'a'`、`'Z' < 'a'` 都为真。

### 2. 课件「思考与练习」逐条解析

下列各表达式的值：

| 表达式 | 值 | 为什么 |
| --- | --- | --- |
| `'b' - 'a'` | `1`（int） | 98 − 97；同组相减 = 字母表距离 |
| `'a' + 2` | `99`（int！） | 提升成 int 再加，**结果是 int 不是 char** |
| `static_cast<char>('a' + 2)` | `'c'` | 把 99 收回 char，cout 才按字符打 |
| `'9' - '0'` | `9`（int） | 57 − 48；**字符数字变真数字的标准写法** |
| `'A' < 'a'` | `true`（1） | 65 < 97 |
| `'Z' < 'a'` | `true`（1） | 90 < 97 |
| `'5' == 5` | `false`（0） | `'5'` 是 53 ≠ 5；**字符 ≠ 数字** |
| `'5' - '0' == 5` | `true`（1） | `-` 优先于 `==`，即 `5 == 5` |

输出语句：

```cpp
char c = 'x';
cout << c << " " << c + 1 << " " << static_cast<char>(c + 1);
// 输出：x 121 y
```

- `c`：类型是 char → 打字符 `x`
- `c + 1`：表达式提升为 int（121）→ 打数字 `121`
- `static_cast<char>(c + 1)`：收回 char → 打字符 `y`

**同一个值，类型决定 cout 怎么打：char 打字符，int 打数字。**

### 3. 两个必背转换公式

已知 `ch` 中存着一个小写字母：

```cpp
char upper = ch - 'a' + 'A';   // 小写 → 大写
int  index = ch - 'a' + 1;     // 字母表序号，a 为 1（b 为 2 …）
```

思路统一为「先减基准、再加目标」：`ch - 'a'` 是它在小写表里排第几（0 起），加 `'A'` 搬进大写表，加 1 变成 1 起的序号。数字字符同理：`ch - '0'` 把 `'7'` 变成真数字 `7`。

### 4. `char c = "A"` 与 `char c = 'AB'`

- `char c = "A";` —— 编译不过。`"A"` 是字符串（`'A'` + `'\0'` 占两个字节），一个 char 装不下，见 K01 易错点。
- `char c = 'AB';` —— **多字符字面量**（multi-character literal）。`'AB'` 不是「两个字符」，类型是 `int`，值由实现定义（常见做法是 `'A'` 占高位、`'B'` 占低位，即 16706），塞进 char 会被截断并给警告。**单引号里永远只写一个字符。**

### 5. 一个字符占几字节？char 能存汉字吗

- 一个 char 恒为 **1 字节**（8 位），最多表达 256 种编码。
- 汉字编不进 1 字节：GBK 里一个汉字占 **2 字节**，UTF-8 里占 **3 字节**。所以**一个 char 存不了一个汉字**，要存汉字得用 `string` 等按编码规则连续存放。

### 易错点

- `'a' + 2` 的类型是 int：不 cast 就 cout 会打出 `99` 而不是 `c`。
- `'5' == 5` 是 false：字符 `'5'` 和数字 5 差着一个 `'0'`；要比较先做 `ch - '0'`。
- `'AB'` 编译能过（顶多警告），但它是 int，语义完全不是「两个字符」。
- 大小写转换写 `ch - 32` 能用但意图不清、只对字母成立；写 `ch - 'a' + 'A'` 自解释。

### 一句话总结

> char 参与运算先提升为 int；抓住 `'0'`、`'A'`、`'a'` 三个基准：减基准得序号或真数字，加基准换回字符，`static_cast<char>` 负责把 int 收回字符世界。

## K04 字符函数 <cctype> —— 判断与转换的现成工具

**考点**：is… 系列返回 int（非 0 即真）、to… 系列返回的也是 int 不是 char、`static_cast<char>` 才能显示字符、调函数 vs 自己按 ASCII 算

### 1. 函数速查表（头文件 `<cctype>`）

| 函数 | 作用 | 示例 → 结果 |
| --- | --- | --- |
| `isdigit(ch)` | 是否为数字字符 | `isdigit('7')` → 真（非 0） |
| `isalpha(ch)` | 是否为字母 | `isalpha('m')` → 真 |
| `isalnum(ch)` | 是否为字母或数字 | `isalnum('#')` → 假（0） |
| `islower(ch)` | 是否为小写字母 | `islower('a')` → 真 |
| `isupper(ch)` | 是否为大写字母 | `isupper('a')` → 假 |
| `isspace(ch)` | 是否为空白字符（空格、`\t`、`\n`） | `isspace(' ')` → 真 |
| `tolower(ch)` | 转为小写（非大写字母则原样返回） | `tolower('G')` → `'g'`，返回 int 103 |
| `toupper(ch)` | 转为大写（非小写字母则原样返回） | `toupper('g')` → `'G'`，返回 int 71 |

### 2. is… 系列：返回 int，非 0 即真

判断结果不是 bool 而是 int：真 → 非 0（常见是 1），假 → 0。**cout 输出时看到的就是一个数**。当条件用没问题，`if` 里非 0 就是真：

```cpp
if (islower(ch)) ...        // ✓ 推荐写法：判断「是不是小写」直接问函数
if (ch >= 'a' && ch <= 'z') ...  // ✓ 等价的手工版（K03 的 ASCII 区间比较）
```

### 3. to… 系列：返回的也是 int！

`tolower` / `toupper` 的返回类型是 int，不是 char——和 K03「`'a' + 2` 是 int」是同一件事：

```cpp
cout << toupper('g');                    // 输出 71！不是 G
cout << static_cast<char>(toupper('g')); // 输出 G —— 要显示字符必须收回 char
```

两个保底行为：**传入的若不是对应大小写的字母，原样返回**（`toupper('7')` 还是 `'7'`），所以不用先判断再转换，直接转是安全的。

### 4. 调函数还是自己算？—— 都要会

| 路线 | 写法 | 价值 |
| --- | --- | --- |
| 调函数 | `islower(ch)`、`toupper(ch)` | 省事、可读、不用记 ASCII 表 |
| 自己算 | `ch >= 'a' && ch <= 'z'`、`ch - 'a' + 'A'` | 明白底层原理，K03 的三基准照样心算 |

课件原话：**函数省事，自己算让你明白原理**。考试两种都可能要求会写。

### 5. 课件补充：遍历字符串时的参数转换

**课件整理，补齐头文件与 `main`。**

```cpp
#include <iostream>
#include <cctype>
using namespace std;

int main() {
    char s[] = "Ab3 x";
    int digits = 0;
    for (int i = 0; s[i] != '\0'; ++i) {
        unsigned char ch = static_cast<unsigned char>(s[i]);
        if (isdigit(ch)) ++digits;
        s[i] = static_cast<char>(toupper(ch));
    }
    cout << s << " " << digits << '\n';
}
```

输出 `AB3 X 1`。

**补充解释。** 循环依次处理 `A`、`b`、`3`、空格、`x`，遇到结束符停止。只有 `3` 让 `digits` 加 1；`b`、`x` 转成大写，其余内容保持原样。

两次转换分别解决不同的问题。调用前的 `static_cast<unsigned char>(s[i])` 保证传入的字符值在字符分类/转换函数允许的范围内，避免普通 `char` 可能为负的情况；这类函数接受的参数应为 `EOF` 或可用 `unsigned char` 表示的值。调用后的 `static_cast<char>(toupper(ch))` 则把返回的 `int` 转回 `char`，存入原数组。

前面“其他字符原样返回”的说明也以参数有效为前提。当前示例中的字符不会触发负值问题，但按课件写出输入侧转换，可以让同样的遍历写法适用于一般的字符字节。

### 易错点

- `cout << toupper('g')` 打出 `71` 不是 `G`——返回 int，忘了 `static_cast<char>` 就露馅。
- `cout << isdigit('7')` 打出 `1`（或非 0 值）不是「真」字——is… 系列当条件用，别直接拿来显示。
- 忘写 `#include <cctype>`。有些环境靠别的头文件间接带进来能编译，别依赖这种侥幸。
- `tolower`/`toupper` 只对字母有转换意义，其他字符原样返回——但返回值类型仍是 int。

### 一句话总结

> `<cctype>` 里 is… 管判断（返回 int，非 0 即真）、to… 管转换（返回的还是 int）；凡是想按字符看到结果，一律 `static_cast<char>`——这正是 K03「类型决定 cout 怎么打」的官方函数版。
