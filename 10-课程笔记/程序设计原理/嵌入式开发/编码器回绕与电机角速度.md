## 最小可编译示例

先独立解决 16 位计数回绕与单位换算。

```cpp
#include <cstdint>
#include <cmath>
#include <cassert>
#include <iostream>

bool delta16(uint16_t now, uint16_t previous, int32_t& delta) {
    uint32_t raw = (uint32_t(now) + 65536U - previous) & 0xFFFFU;
    if (raw == 32768U) return false;
    delta = raw < 32768U ? int32_t(raw) : int32_t(raw) - 65536;
    return true;
}
bool angularSpeed(int32_t delta, float dt, float& omega) {
    if (!std::isfinite(dt) || dt <= 0.0f) return false;
    constexpr float countsPerTurn = 3960.0f;
    constexpr float twoPi = 6.2831853071795864769f;
    omega = float(delta) / countsPerTurn * twoPi / dt;
    return std::isfinite(omega);
}
int main() {
    int32_t delta = 0;
    float omega = 0;
    assert(delta16(8, 65530, delta) && delta == 14);
    assert(angularSpeed(delta, 0.01f, omega) && omega > 0);
    std::cout << "omega=" << omega << " rad/s\n";
    assert(delta16(65530, 8, delta) && delta == -14);
    assert(!delta16(32768, 0, delta));
    assert(!angularSpeed(14, 0.0f, omega));
}
```

这个求差方法要求两次采样之间真实计数变化的绝对值小于 32768。恰好半圈计数模数时方向无法确定；走了整圈计数模数后，两次读数甚至可能相同。因此不能仅凭差值小，就证明没有多次回绕。

## 可替换的测速与电机接口骨架

把上述两个函数放入 `encoder_math.hpp`，去掉测试 `main`。板卡绑定必须由现有工程提供。电机接口按章 README 中“一路 PWM 加两路方向信号”的形式示范，仅适用于具备这种接口且逻辑已确认的驱动。

```cpp
#include "main.h"
#include "encoder_math.hpp"
#include <cmath>

struct OutputPin { GPIO_TypeDef* port; uint16_t pin; };
extern TIM_HandleTypeDef& appEncoderTimer;
extern TIM_HandleTypeDef& appMotorTimer;
extern const uint32_t appMotorChannel;
extern const OutputPin appMotorIn1, appMotorIn2;
static uint16_t previousCount = 0;
static uint32_t previousMs = 0;
volatile float appOmegaRadps = 0;
volatile bool appSpeedValid = false;

bool App_SetMotorDuty(float signedDuty) {
    uint32_t arr = __HAL_TIM_GET_AUTORELOAD(&appMotorTimer);
    __HAL_TIM_SET_COMPARE(&appMotorTimer, appMotorChannel, 0U);
    if (arr >= 65535U) return false;
    bool valid = std::isfinite(signedDuty);
    if (!valid) signedDuty = 0;
    if (signedDuty > 1) signedDuty = 1;
    if (signedDuty < -1) signedDuty = -1;
    HAL_GPIO_WritePin(appMotorIn1.port, appMotorIn1.pin,
                      signedDuty > 0 ? GPIO_PIN_SET : GPIO_PIN_RESET);
    HAL_GPIO_WritePin(appMotorIn2.port, appMotorIn2.pin,
                      signedDuty < 0 ? GPIO_PIN_SET : GPIO_PIN_RESET);
    uint32_t compare = uint32_t(std::lround(std::fabs(signedDuty) * (arr + 1U)));
    __HAL_TIM_SET_COMPARE(&appMotorTimer, appMotorChannel, compare);
    return valid;
}
HAL_StatusTypeDef App_EncoderBegin() {
    if (appEncoderTimer.Instance == appMotorTimer.Instance) return HAL_ERROR;
    if (__HAL_TIM_GET_AUTORELOAD(&appEncoderTimer) != 65535U) return HAL_ERROR;
    if (!App_SetMotorDuty(0)) return HAL_ERROR;
    HAL_StatusTypeDef status = HAL_TIM_PWM_Start(&appMotorTimer, appMotorChannel);
    if (status != HAL_OK) return status;
    status = HAL_TIM_Encoder_Start(&appEncoderTimer, TIM_CHANNEL_ALL);
    if (status != HAL_OK) return status;
    previousCount = uint16_t(__HAL_TIM_GET_COUNTER(&appEncoderTimer));
    previousMs = HAL_GetTick();
    appOmegaRadps = 0; appSpeedValid = false;
    return HAL_OK;
}
void App_EncoderStep() {
    uint32_t nowMs = HAL_GetTick();
    uint32_t elapsed = uint32_t(nowMs - previousMs);
    if (elapsed < 10U) return;
    uint16_t count = uint16_t(__HAL_TIM_GET_COUNTER(&appEncoderTimer));
    int32_t delta = 0;
    float omega = 0;
    bool valid = delta16(count, previousCount, delta)
              && angularSpeed(delta, float(elapsed) / 1000.0f, omega);
    previousCount = count; previousMs = nowMs;
    appSpeedValid = valid;
    appOmegaRadps = valid ? omega : 0;
    if (!valid) App_SetMotorDuty(0);
}
// GPIO、PWM TIM、编码器 TIM 初始化后检查 App_EncoderBegin() 的状态。
// 主循环调用 App_EncoderStep()；开始时占空比保持零。
// 硬件逻辑确认后，可由自己的控制入口调用 App_SetMotorDuty(...)。
```

正负占空比在本接口中的约定分别为 IN1 高、IN2 低，以及 IN1 低、IN2 高；零指令关闭 PWM，两个方向信号为低。实际轴正方向、编码器计数正方向、驱动的使能有效电平、停机与换向要求都须核对。代码先清比较值再改变方向，但没有代替具体驱动所要求的换向死区或制动流程。若驱动接口不同，应替换整个 `App_SetMotorDuty`。

## 语法、API 与寄存器解析

`uint16_t` 存原始计数，`int32_t` 存有正负意义的差值。表达式先提升到 32 位再做模 65536 的差，避免依赖超范围的有符号整数转换。`& 0xFFFFU` 保留低 16 位；减去 65536 把较大的模差转换成负方向差。引用形参 `int32_t&` 和 `float&` 用于输出结果，布尔返回值表示本次计算有效与否。

`constexpr` 给出计数比例和 $2\pi$；用浮点数除法避免整数除法提前截断。角速度为 $\omega=\Delta N\,2\pi/(3960\Delta t)$，单位 rad/s；转速为 $\Delta N\,60/(3960\Delta t)$，单位转/分钟。这里一圈指讲义按减速比折算后的输出轴一圈，必须与观察轴保持一致。

`HAL_TIM_Encoder_Start(..., TIM_CHANNEL_ALL)` 启动编码器输入通道。CubeMX 应选择与四倍频相符的 TI12 模式，同时核对 AB 相引脚、滤波与输入极性；不能一面选择其他计数倍率，一面仍用 3960 作分母。`__HAL_TIM_GET_COUNTER` 读 CNT，这才是累积计数。`HAL_TIM_ReadCapturedValue` 读 CCR 捕获寄存器，不能用它替代 CNT。DIR 仅描述当前计数方向，也不能代替一个采样区间的有符号净计数。

ARR=65535 对应本算法假定的 65536 模数，故代码启动时检查 ARR。测速和电机 PWM 需要不同定时器实例，同一定时器的共享计数基准不能同时承担这两种配置。`HAL_GetTick` 提供毫秒时钟；本骨架至少隔 10 毫秒采样，并使用实际经过时间换算，没有把主循环伪装成精确 10 毫秒调度。若课程要求精确 1 毫秒周期，应配置定时触发并单独核验执行时序。

电机 PWM 的 CCR 根据幅值设置；使用 ARR+1 作为分母。限制 ARR 不超过 65534，使 16 位比较寄存器能表示满占空比的 ARR+1。`std::fabs` 取幅值，`std::lround` 四舍五入到计数。`volatile` 让调试器和异步观察能看到更新，但不为多个相关状态提供原子快照；需一致读取计数、速度与有效标志时，应由主循环统一取样或加同步。

## 控制流程、常见错误与最小自检

先保持电机输出为零，启动 PWM 与编码器，保存初始计数和时间；达到采样间隔后读 CNT、计算模差、换算角速度并更新基线。有效标志为假时输出零速度并停机，不能把这类样本当作正常静止数据。确认测量符号和比例之后，控制入口再给正负占空比；本题骨架没有新增 PID 速度闭环。

常见错误是把 CNT 当普通有符号数直接相减，在回绕时产生巨大假速度；每次清零导致读写间隙漏计；角速度分母使用毫秒却当成秒；浮点换算前先做整数除法；漏掉四倍频或重复乘四；把电机轴脉冲数与减速输出轴圈数混用；用同一定时器做编码器和 PWM。

最小自检运行电脑例子，正向从 65530 到 8 应得到 +14，反向从 8 到 65530 应得到 -14；半模差 32768 必须报告歧义。模拟每 10 毫秒增加 396 计数时，应得到 10 转/秒，即约 62.83 rad/s。再检查零时间、NaN 时间、ARR 不匹配与重复定时器配置。实物上先手动转动已确认的输出轴一圈，观察净计数是否接近 3960，并检查两个方向的符号。
