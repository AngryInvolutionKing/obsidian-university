# 05 整型截断

**考点**：窄化转换保留低位

## 题目

读入一个 `int`，分别输出把它转成 `short`、`unsigned char` 之后的值。

## 代码

```cpp
void solve05() {
    int x;
    cin >> x;

    short s         = (short)x;           // 低 16 位，有符号解释
    unsigned char c = (unsigned char)x;   // 低 8 位，无符号解释

    cout << s << " " << (int)c << "\n";
}
```

## 要点

- 转窄类型时保留低位：`short` 留低 16 位，`unsigned char` 留低 8 位。
- 同一串 bit，按有符号解释可能是负数，按无符号解释就是 0 ~ 255。
- 输出前把 `c` 转成 `int`，否则 `cout` 会把它当字符打印。

## 坑

- `cout << c` 打印的是一个字符（比如 65 打出来是 `A`），不是数字。
- 别把 `char` 和 `signed char` 混为一谈，`char` 是否有符号要看平台。
