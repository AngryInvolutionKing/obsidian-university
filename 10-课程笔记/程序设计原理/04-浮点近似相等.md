# 04 浮点近似相等

**考点**：浮点误差，别用 `a == b` 比较

## 题目

读入两个浮点数 a、b，认为它们近似相等时输出 `EQUAL`，否则输出 `NOT EQUAL`。

## 代码

```cpp
void solve04() {
    double a, b;
    cin >> a >> b;

    double diff  = fabs(a - b);
    double scale = max(1.0, max(fabs(a), fabs(b)));   // 至少为 1

    if (diff <= 1e-9 * scale) {
        cout << "EQUAL\n";
    } else {
        cout << "NOT EQUAL\n";
    }
}
```

## 要点

- 浮点数是二进制近似值，`0.1 + 0.2 != 0.3`，所以判断相等要看"差得够不够小"。
- 判据是相对误差：`diff <= 1e-9 * scale`，数越大允许的绝对误差越大。
- `scale` 至少取 1：a、b 都接近 0 时，容差就退化成绝对误差 `1e-9`，还算合理。

## 坑

- `fabs` 来自 `<cmath>`；`abs` 是整数版，写混了会得到奇怪结果。
- 别用 `a == b` 或手写 `1e-6` 硬编码却不考虑量级。
