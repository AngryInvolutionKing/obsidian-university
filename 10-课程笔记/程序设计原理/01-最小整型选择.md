# 01 最小整型选择

**考点**：`short` / `int` / `long long` 的值域

## 题目

读入一个整数 `x`，输出能装下它的最小整型名：`short`、`int` 或 `long long`。

## 代码

```cpp
void solve01() {
    long long x;
    cin >> x;

    if (x >= SHRT_MIN && x <= SHRT_MAX) {
        cout << "short\n";
    } else if (x >= INT_MIN && x <= INT_MAX) {
        cout << "int\n";
    } else {
        cout << "long long\n";
    }
}
```

## 要点

- `SHRT_MIN/SHRT_MAX`、`INT_MIN/INT_MAX` 来自 `<climits>`，比手写 `-32768` 可靠。
- 输入必须用 `long long` 接住。用 `int` 读的话，超范围那一刻就已经出问题了，后面再判断没有意义。
- 判断顺序从小到大：先试 `short`，装不下再 `int`，最后 `long long`。

## 坑

- 别把值域写成魔数：不同平台上 `int` 不一定是 32 位。
- `long` 在 Windows 是 32 位，在 64 位 Linux/macOS 是 64 位，所以这里用 `long long`。
