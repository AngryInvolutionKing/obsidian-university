# 08 位运算开关

**考点**：位运算（`|`、`&`、`^`、`~`、`<<`）、掩码

## 题目

输入一个 `int`，当作 32 个开关（1 打开、0 关闭）。再输入第几位 p（0~31）和操作类型 op（0 关闭 / 1 打开 / 2 反转），改完输出这个整数。

## 思路

**第 p 位就是 2 的 p 次方那个位置**：第 0 位是 1，第 1 位是 2，第 2 位是 4……

掩码 `1u << p`：只有第 p 位是 1，其余全是 0。

样例 `4 0 1`：

```
4 = ...000100
    第 0 位是 0，op = 1 打开 -> ...000101 = 5
```

三个操作正好对应三个运算符：

| 操作   | 写法              | 效果                         |
| ---- | --------------- | -------------------------- |
| 1 打开 | `data \|= mask` | 和 1 做**或**，该位必定变 1         |
| 0 关闭 | `data &= ~mask` | mask 取反后该位是 0，**与**运算把它清 0 |
| 2 反转 | `data ^= mask`  | 和 1 做**异或**，1 变 0、0 变 1    |

其它 31 位因为是和「1 保持原样」做运算，完全不受影响。

## 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int data;       // 32 个开关
    int p;          // 第几位，0 ~ 31
    int op;         // 0 关闭, 1 打开, 2 反转
    cin >> data >> p >> op;

    unsigned int mask = 1u << p;    // 只有第 p 位是 1，其余全 0

    if (op == 0) {
        data &= ~mask;      // 关闭：第 p 位清 0
    } else if (op == 1) {
        data |= mask;       // 打开：第 p 位置 1
    } else {
        data ^= mask;       // 反转：第 p 位取反
    }

    cout << data << endl;
    return 0;
}
```

## 要点

- 记忆办法：**或**用来开、**与上取反**用来关、**异或**用来翻转。
- 掩码写 `1u << p`：`p = 31` 时 `1 << 31` 对 `int` 是有符号溢出（UB），加 `u` 才安全。

## 坑

- 第 31 位被置 1 时，按有符号输出是负数（`0 31 1` -> `-2147483648`）。若判题系统要的是 `2147483648`，最后一行改用 `cout << (unsigned int)data << endl;`
- 别用 `pow(2, p)`：那是浮点函数，这题要的是位运算。

## 测试记录

```
4 0 1   -> 5
7 1 0   -> 5
5 0 2   -> 4
0 31 1  -> -2147483648
-1 31 0 -> 2147483647
```

## 位运算语法补充

**六个运算符**

| 写法       | 名称   | 规则                     | 常见用途                   |
| -------- | ---- | ---------------------- | ---------------------- |
| `a & b`  | 按位与  | 两位都是 1 才是 1            | 取某些位、判断奇偶、清 0          |
| `a \| b` | 按位或  | 有一位是 1 就是 1            | 把指定位置 1                |
| `a ^ b`  | 按位异或 | 两位不同才是 1               | 翻转、交换两个数               |
| `~a`     | 按位取反 | 单目，0 变 1、1 变 0         | 配合 `&` 清 0             |
| `a << n` | 左移   | 右边补 0，等于乘 2 的 n 次方     | 造掩码 `1u << p`          |
| `a >> n` | 右移   | 等于整除 2 的 n 次方；无符号一定补 0 | 取第 p 位 `(x >> p) & 1u` |

复合赋值：`a &= b`、`a |= b`、`a ^= b`、`a <<= n`、`a >>= n`，就是 `a = a 运算 b` 的缩写。

**优先级**（从高到低）

```
~   <<  >>   &   ^   |
```

它们都比 `+ - * /` 低，但 `&` 比 `a == b` 低，所以下面这种写法是错的：

```cpp
if (x & 1 == 0)     // 实际是 x & (1 == 0)，即 x & 0，永远为假
if ((x & 1) == 0)   // 正确
```

记法：位运算一律套括号。

**移位规矩**

- 移位数必须小于类型宽度，`1u << 32` 是未定义行为。
- `1 << 31` 也是 UB（`int` 装不下 2147483648），要写 `1u << 31`。
- `char`、`short` 参与位运算会先提升成 `int`，符号问题就是这么来的；开头写 `1u` 可以躲开这类坑。
- 对负数右移是实现定义行为（g++ 是算术右移，`-8 >> 1 == -4`），别依赖。

**常用套路**

| 目的 | 写法 |
| --- | --- |
| 取第 p 位 | `(x >> p) & 1u` |
| 第 p 位置 1 | `x \|= 1u << p` |
| 第 p 位清 0 | `x &= ~(1u << p)` |
| 第 p 位翻转 | `x ^= 1u << p` |
| 取低 8 位 | `x & 0xFF` |
| 判断奇偶 | `x & 1` |
| 乘 / 除 2 的 k 次方 | `x << k` / `x >> k` |
| 只留最低位那个 1 | `x & -x` |
| 交换两个整数 | `a ^= b; b ^= a; a ^= b;` |

标准库还有现成的：`<bitset>` 里的 `bitset<32> s(x);`，配 `s[p]`、`s.flip(p)`、`s.count()`；C++20 的 `<bit>` 里有 `popcount`（数 1 的个数）、`rotl` / `rotr`（循环移位）。

## 不定义 mask 变量的写法

不用中间变量，把掩码直接写成表达式 `1 << b`，一个分支一行：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a;
    cin >> b;
    cin >> c;

    if (c == 0) {
        a &= ~(1 << b);      // 关闭：第 b 位清 0
    } else if (c == 1) {
        a |= (1 << b);       // 打开：第 b 位置 1
    } else {
        a ^= (1 << b);       // 反转：第 b 位取反
    }

    cout << a << endl;
    return 0;
}
```

### 要点

- `1 << b` 就是「只有第 b 位是 1」的那个数，和起名叫 `mask` 的变量完全等价，只是省掉了名字。
- `~(1 << b)` 是「除了第 b 位全是 1」，所以 `a &= ~(1 << b)` 只清掉第 b 位，其它 31 位原样保留。
- 三个分支的分工：`&` 用来关、`|` 用来开、`^` 用来翻转。

### 坑

- 括号不能省。`~(1 << b)` 少了括号会变成 `~1 << b`，也就是 `(-2) << b`，结果完全不对。
- 保险写法是把 `1 << b` 写成 `1u << b`。`b = 31` 时 `1 << 31` 是 2147483648，`int` 装不下，标准里属于未定义行为；g++ 上 O0、O2 都能得到预期结果，但换编译器或优化级别就没有保证。
- 输入顺序是 a（32 个开关）、b（第几位）、c（操作类型），和题目一致，别读反。

### 测试记录

```
4 0 1   -> 5
7 1 0   -> 5
5 0 2   -> 4
0 31 1  -> -2147483648
-1 31 0 -> 2147483647
-8 3 0  -> -16
-8 3 2  -> -16
```

这份写法和 `1u << p` 掩码版用 60 组随机输入（含负数、p 取到 31）交叉比对，O0 和 O2 两种优化级别输出完全一致。
