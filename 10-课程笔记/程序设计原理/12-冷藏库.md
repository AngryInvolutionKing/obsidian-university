# 12-冷藏库

## 题意

冷链仓库每分钟记录一次温度。一个连续时段称为**稳定时段**，当且仅当该时段内最高温度与最低温度之差不超过阈值 $D$。

给定 $n$ 次温度记录，求：

1. 最长稳定时段的**长度**；
2. 达到最长长度的时段**数量**；
3. 这些时段中**字典序最小**的一段（先比左端点，再比右端点）的左右端点（按时间从 1 开始编号）。

多组测试数据，每组输出四个整数：`长度 数量 左端点 右端点`。

## 核心思路：滑动窗口 + 单调队列

关键观察——稳定性具有**区间继承性**：

- 稳定区间的任意子区间一定稳定（子区间的极差 ≤ 原区间的极差）；
- 包含不稳定区间的区间一定不稳定。

因此固定左端点 $l$ 时，能延伸的最远右端点 $R[l]$ 存在，且 $l$ 右移时 $R[l]$ **单调不减** → 可以用双指针在 $O(n)$ 内求出所有 $R[l]$。

区间极差需要动态维护窗口内最大/最小值 → 用两个**单调队列**：

- `mx`：存下标，对应值从队首到队尾**递减**，队首即窗口最大值；
- `mn`：存下标，对应值从队首到队尾**递增**，队首即窗口最小值。

求出全部 $R[l]$ 后，`len = R[l] - l + 1`，一次线性扫描统计最大长度、个数和字典序最小的端点即可。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        long long D;
        cin >> n >> D;
        vector<long long> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];

        vector<int> R(n);       // R[l] = 以 l 为左端点的最远右端点（闭区间）
        deque<int> mx, mn;      // 存下标：mx 值递减(队首最大)，mn 值递增(队首最小)
        int r = 0;              // 当前窗口 [l, r)

        for (int l = 0; l < n; l++) {
            while (r < n) {
                long long nMax = mx.empty() ? a[r] : max(a[mx.front()], a[r]);
                long long nMin = mn.empty() ? a[r] : min(a[mn.front()], a[r]);
                if (nMax - nMin > D) break;   // 纳入 a[r] 就不稳定，停止扩张

                while (!mx.empty() && a[mx.back()] <= a[r]) mx.pop_back();
                mx.push_back(r);
                while (!mn.empty() && a[mn.back()] >= a[r]) mn.pop_back();
                mn.push_back(r);
                ++r;
            }
            R[l] = r - 1;

            if (!mx.empty() && mx.front() == l) mx.pop_front();   // 左端点出窗口
            if (!mn.empty() && mn.front() == l) mn.pop_front();
        }

        int bestLen = 0, bestCnt = 0, bestLeft = 1;
        for (int l = 0; l < n; l++) {
            int len = R[l] - l + 1;
            if (len > bestLen) {
                bestLen = len;
                bestCnt = 1;
                bestLeft = l + 1;             // 最后长度相同就不再改，天然是字典序最小
            } else if (len == bestLen) {
                bestCnt++;
            }
        }
        cout << bestLen << " " << bestCnt << " "
             << bestLeft << " " << bestLeft + bestLen - 1 << "\n";
    }
    return 0;
}
```

## 代码逐块解析

### 1. 双指针主体：求 R[l]

```cpp
for (int l = 0; l < n; l++) {
    while (r < n) { ... }        // 能扩就扩
    R[l] = r - 1;                // 窗口 [l, r) 是稳定的，闭区间右端点为 r-1
    ...                          // l 出窗口，进入下一轮
}
```

- 窗口用**左闭右开** `[l, r)` 表示，所以最远合法闭区间的右端点是 `r - 1`。
- `r` 从不回退：$l$ 增大时窗口变小只会更稳定，最远端点不可能变近，这是双指针正确性的核心。
- **单元素区间永远稳定**（极差为 0 ≤ D），所以空窗口时扩张必然成功，保证 `R[l] >= l`，答案长度至少为 1，不存在越界。

> [!info]- `r` 到底是什么
> `r` 不是"窗口里最右的元素"，而是**下一个还没进窗口的元素下标**。窗口 `[l, r)` 里实际装着 `a[l..r-1]`：
>
> ```
> 下标:    0    1    2    3    4
>  a:     [3]  [1]  [5]   8    6
>          └───窗口 [0, 3)──┘   ↑
>          ↑                    r = 3（下一个待纳入者）
>        l = 0
> ```
>
> `r` 的完整一生：初始化 0（`l == r` 即空窗口）→ 试探 `a[r]` 稳定就入队并 `++r` → 不稳定 `break` 卡住 → 记 `R[l] = r - 1` → `l++` 而 `r` 不回退。
>
> 不回退的原因：$l$ 右移窗口变小、极差更小、只会更稳定，所以 $R[l+1] \ge R[l]$。于是 `r` 全程从 0 走到 n 只走 $n$ 步，总复杂度 $O(n)$；若每个 $l$ 都让 `r` 从头扩就是 $O(n^2)$。

### 2. 单调队列的维护（入队 + 试探）

```cpp
long long nMax = mx.empty() ? a[r] : max(a[mx.front()], a[r]);
long long nMin = mn.empty() ? a[r] : min(a[mn.front()], a[r]);
if (nMax - nMin > D) break;
```

- **先试探、后入队**：假设把 `a[r]` 纳入窗口，用当前队首（旧窗口极值）和 `a[r]` 取 max/min 得到新极值；若极差超 `D` 就 `break`，`a[r]` 不入队。
- 这样队列里的下标始终严格对应真实窗口 `[l, r)`，不需要任何"撤销"操作。
- 空窗口分支（`mx.empty()`）处理了上一轮 `break` 后 $l$ 追上 $r$、窗口变空的情形。

> [!note]- 语法拆解：`? :` 三目运算符
> `条件 ? A : B`：条件成立整个式子取 A，否则取 B，是 if-else 的"表达式版"（if-else 是语句，不能写在赋值号右边；三目运算符本身是个值）。
>
> ```cpp
> long long nMax = mx.empty() ? a[r] : max(a[mx.front()], a[r]);
> //               └─ 条件 ──┘ └─A─┘  └─────────B──────────┘
> ```
>
> 等价于：
>
> ```cpp
> long long nMax;
> if (mx.empty()) {
>     nMax = a[r];                      // 窗口空，没有旧最大值
> } else {
>     nMax = max(a[mx.front()], a[r]);  // 新最大值 = max(旧最大值, a[r])
> }
> ```
>
> `max(x, y)` / `min(x, y)` 是标准库函数，返回两者较大/较小者。判空不可省：空队列调 `front()` 是未定义行为。

```cpp
while (!mx.empty() && a[mx.back()] <= a[r]) mx.pop_back();
mx.push_back(r);
while (!mn.empty() && a[mn.back()] >= a[r]) mn.pop_back();
mn.push_back(r);
```

- 新元素入队前，从**队尾**弹掉所有被它"压制"的元素：
  - `mx` 中弹出值 `<= a[r]` 的——它们比 `a[r]` 小又比它早过期，永远不可能再成为最大值；
  - `mn` 中弹出值 `>= a[r]` 的——同理不可能再成为最小值。
- 每个下标最多入队、出队各一次 → 均摊 $O(1)$。

```cpp
if (!mx.empty() && mx.front() == l) mx.pop_front();
if (!mn.empty() && mn.front() == l) mn.pop_front();
```

- `l++` 之前，把已经滑出窗口的左端点从**队首**弹出。
- 单调队列中下标从队首到队尾严格递增，所以若 $l$ 还在队列里，必在队首——只查 `front() == l` 即可，无需遍历。
- 判空必须写：窗口可能为空（$r = l$ 时），此时没有可弹的队首。

### 3. 单调队列详解：deque 到底在干什么

**deque 本身**：双端队列，两头都能 $O(1)$ 插入/删除。"单调队列"不是新数据结构，而是**往 deque 里存下标、并让对应的值保持单调**的一种用法。

成员函数速查（代码里用到的全部 6 个）：

| 函数               | 干什么           | 返回值            | 记忆法       |
| ---------------- | ------------- | -------------- | --------- |
| `q.push_back(x)` | x 从**队尾**进队   | 无              | push = 塞入 |
| `q.pop_back()`   | 删掉**队尾**元素    | 无              | pop = 删除  |
| `q.pop_front()`  | 删掉**队首**元素    | 无              | pop = 删除  |
| `q.front()`      | 看一眼**队首**（不删） | 队首元素           | 只看不动      |
| `q.back()`       | 看一眼**队尾**（不删） | 队尾元素           | 只看不动      |
| `q.empty()`      | 队列是否为空        | `true`/`false` | 空 = true  |

```
      队首（最老）                    队尾（最新）
        ↓                              ↓
      ┌────┬────┬────┐
      │ 0  │ 2  │ 5  │    ← deque 里装的是下标
      └────┴────┴────┘
        ↑                              ↑
   front() 看这头                back() 看这头
   pop_front() 从这头删          push_back(x) 进 / pop_back() 删
```

> [!warning] 空队列不能碰
> 对空队列调用 `front()`、`back()`、`pop_*()` 是未定义行为。所以代码里到处是 `!mx.empty() && ...` 这种"先判空再操作"的固定搭配（`!` 读作"非"，`!mx.empty()` = 队列不空）。

**要解决的问题**：窗口每变一步都要立刻知道当前窗口最大值；每次重扫窗口是 $O(n^2)$ 总复杂度。单调队列让**队首永远就是最大值**，查询 $O(1)$。

**核心直觉："又大又新" 淘汰 "又小又旧"**。mx 里只留"还有资格当未来最大值"的下标。比较两个候选 $i < j$：若 $a_i \le a_j$，则 $i$ 彻底没用——$i$ 在窗口里的每一天 $j$ 必然也在（$j$ 更靠右、更晚过期），而比大小永远 $a_j \ge a_i$。所以 `a[r]` 入队前，把队尾所有值 $\le a[r]$ 的老下标全踢掉。由此保持两条不变量：

1. 下标从队首到队尾**严格递增**（老 → 新）；
2. 值从队首到队尾**严格递减**。

⇒ **队首 = 当前窗口最大值**；mn 完全对称（踢 $\ge a[r]$，值递增，队首 = 最小值）。

**为什么存下标不存值**：$l$ 前进时要判断队首是否滑出窗口，只有下标能判断过期；又因为队列内下标递增，最老的下标恰在队首，所以只需 `if (mx.front() == l) mx.pop_front()` 一句。

**逐步演示**（只看 mx，`a = [3, 1, 5, 8, 6]`，假设无 D 限制、窗口一路扩张）：

| 新元素入队 | 队尾淘汰过程 | 队列状态（下标:值） | 队首 = 窗口最大值 |
| --- | --- | --- | --- |
| 入 3 | 空队，直接进 | `[0:3]` | 3 ✓ |
| 入 1 | 队尾 3 > 1，没人被踢 | `[0:3, 1:1]` | 3 = max(3,1) ✓ |
| 入 5 | 踢 1 → 踢 3 → 队空 | `[2:5]` | 5 = max(3,1,5) ✓ |
| 入 8 | 踢 5 | `[3:8]` | 8 ✓ |
| 入 6 | 队尾 8 > 6，没人被踢 | `[3:8, 4:6]` | 8 = max(8,6) ✓ |

再看"过期弹出"：左端点 $l$ 右移到 4 时，队首下标 3 出窗口 → `pop_front()`，队列变 `[4:6]`，队首自动更新为新最大值 6。

> [!info] 与真实代码的关系
> 本题代码里 8 在 $l=0,1$ 时会触发 `break`（8−1=7 > 4）暂不入队，到 $l=2$ 才入队；单调队列自身的淘汰规则与上表完全相同。

**为什么是 $O(n)$**：每个下标至多入队一次、出队一次（从队尾被踢也算出队），总操作 $\le 2n$，均摊每个元素 $O(1)$。

### 4. 统计答案：长度、个数、字典序

```cpp
int len = R[l] - l + 1;
if (len > bestLen)      { bestLen = len; bestCnt = 1; bestLeft = l + 1; }
else if (len == bestLen)  bestCnt++;
```

- 扫描每个左端点对应的长度，维护最大值 `bestLen` 与出现次数 `bestCnt`。
- **字典序最小是"白拿"的**：所有候选时段长度都等于 `bestLen`，右端点 = 左端点 + bestLen − 1，于是 $(l, r)$ 的字典序比较退化为只比 $l$。从左往右扫、只在**严格大于**时更新 `bestLeft`，留下的自然就是最靠左（即字典序最小）的那段。
- 输出时 `l + 1` 把 0-indexed 转成题目要求的 1-indexed，右端点为 `bestLeft + bestLen - 1`。

## 手算走一遍

`a = [3, 1, 5, 8, 6]`，`D = 4`：

| $l$ | 最远窗口 | $R[l]$ | 长度 | 说明 |
| --- | --- | --- | --- | --- |
| 0 | `[3, 1, 5]` | 2 | 3 | 再纳入 8 后极差 8−1=7 > 4，停 |
| 1 | `[1, 5]` | 2 | 2 | 同上，纳入 8 仍超 |
| 2 | `[5, 8, 6]` | 4 | 3 | 8−5=3 ≤ 4，到数组末尾 |
| 3 | `[8, 6]` | 4 | 2 | — |
| 4 | `[6]` | 4 | 1 | — |

最大长度 3，出现 2 次（$l=0$ 和 $l=2$），字典序最小为左端点 1。

输出：`3 2 1 3` ✓

## 复杂度

- **时间 $O(n)$**（每组数据）：`r` 只增不减，总扩张 ≤ $n$ 次；每个下标在两个队列里各至多进/出一次；`break` 每轮 $l$ 至多发生一次；统计扫描 $O(n)$。
- **空间 $O(n)$**：`R` 数组 + 两个队列。

## 易错点

> [!warning] 溢出
> 温度值可能很大，`a[mx.front()] - a[mn.front()]` 若用 `int` 相减会溢出，所以 `D` 和 `a` 都用 `long long`。

> [!warning] 队列要每组重置
> `R`、`mx`、`mn`、`r` 都声明在 `while (T--)` **内部**，多组数据自动清空；若挪到外面忘记清空会跨组串数据。

> [!tip] 先试探后入队的顺序
> 若先把 `a[r]` 入队再检查，一旦超阈值还得从队尾"撤回"，容易写错；先试探的写法保证队列永远精确对应当前窗口。

> [!tip] 字典序不用额外排序
> 候选段等长 ⇒ 比字典序等价于比左端点 ⇒ 从左往右扫 + 严格大于才更新即可，不要写多余的 pair 比较。
