# 07 阶乘与溢出边界

**考点**：`unsigned long long` 极值、乘法前先判溢出

## 题目

读入 n，输出 n!；如果超过 `unsigned long long` 能表示的范围，输出 `OVERFLOW`。

## 代码

```cpp
void solve07() {
    int n;
    cin >> n;

    unsigned long long fact = 1;
    bool overflow = false;

    for (int i = 2; i <= n; ++i) {
        // 乘法前先判断，避免先乘后判的 UB
        if (fact > ULLONG_MAX / i) {
            overflow = true;
            break;
        }
        fact *= i;
    }

    if (overflow) cout << "OVERFLOW\n";
    else          cout << fact << "\n";
}
```

## 要点

- 判断方式是 `fact > ULLONG_MAX / i`：等价于问"`fact * i` 会不会超过上限"，但除法本身不会溢出。
- `ULLONG_MAX` 来自 `<climits>`，64 位平台上约 1.8e19，20! 还装得下，21! 就爆了。
- 无符号溢出会按模回绕，结果是个看着"正常"的错数，所以要提前拦住。

## 坑

- 不能先乘、再和 `ULLONG_MAX` 比：那时已经错了，而且有符号版本还是 UB。
- 累乘的初值必须是 1，写 0 的话结果永远是 0。
