# 11 小孩姐永不妥协（平方操作凑非递减 · 贪心）

**考点**：从左到右贪心（每首歌取「刚好不低于前一首」的最小平方次数）、指数爆炸的数值不进大数（两边取对数，把「至少平方几次」压成**闭式** $k=\lceil cnt+\log_2\frac{\ln p}{\ln q}\rceil$）、`ceill` 前的 `1e-9` 容差、$\ln 1 = 0$ 作真数 / 作除数两个必须先挡的分支、答案用 `long long` 的溢出边界

> 多组测试的算法题，题面用乐队故事包装：操作是「平方」，目标是非递减，求最少次数。解法是从左到右的贪心；全题唯一的难点是**平方后的数值是 $2^{2^{10^5}}$ 量级的塔、任何类型都存不下**——两边取对数，「最少平方几次」就有闭式解，连搜索都省了，见「解法」。

## 题目

井芹仁菜正在为“无刺有刺”乐队排练下一次 Live 的歌单。她一共挑选了 $n$ 首歌曲，每首歌都拥有一个初始的“感染力”数值 $a_i$。

仁菜对音乐有着绝不妥协的纯粹，正如身为“不登校”少女的她，对世界上所有的“不讲理”都抱有强烈的抵触。她深信：一场震撼人心的完美演出，其情绪必须是层层递进的。也就是说，歌单中后一首歌的感染力绝对不能低于前一首歌（即必须满足 $a_1 \le a_2 \le \cdots \le a_n$）。一旦情绪回落，对她而言就如同向虚伪的现实低头妥协。

为了带来“完美演出”，仁菜可以对位置 $i$（$1 \le i \le n$）的歌曲进行一次“倾力演绎”：为其注入自己全部的灵魂与呐喊。每当仁菜进行一次“倾力演绎”，这首歌的情感就会发生指数级的蜕变，其感染力瞬间平方（即从当前的 $a_i$ 变成 $a_i^2$）。

为了达到完美的承接效果，仁菜可以对同一首歌进行任意多次的“倾力演绎”。每多演绎一次，它当前的感染力就会再次平方（例如，如果对同一首歌连续进行两次倾力演绎，它的感染力就会从 $a_i$ 变为 $a_i^2$，再变为 $a_i^4$）。当然，对于已经足够震撼的歌曲，她也可以不进行任何额外的演绎。

现在给定每首歌的初始感染力，请你帮桃香计算一下：仁菜最少需要进行多少次“倾力演绎”，才能让整场 Live 的歌单感染力呈现完美的非递减状态？

如果你发现即便仁菜再怎么倾注心血，也无法使演出完美。此时，请输出 -1。

## 输入描述

第一行包含一个整数 $t$（$1 \le t \le 1000$），表示测试用例的数量。

每个测试用例的第一行包含一个整数 $n$（$1 \le n \le 2 \cdot 10^5$），表示歌单中歌曲的数量。

第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 10^6$），表示每首歌的初始感染力。

所有测试用例的 $n$ 之和不超过 $2 \cdot 10^5$。

## 输出描述

对于每个测试用例，输出一个整数 —— 仁菜让歌单感染力非递减所需的最少“倾力演绎”总次数。如果无论如何也无法做到，输出 -1。

## 解法：从左到右贪心（对数闭式）

### 三个观察

1. **操作对单首歌是单调的**：$a_i \ge 2$ 时平方严格变大，$a_i = 1$ 时平方永远不变。所以第 $i$ 首歌的可达值集是 $\{a_i^{2^k} \mid k \ge 0\}$，随 $k$ 单调不降——「演绎几次」是这首歌唯一的决策变量。
2. **贪心：每首歌取最小可行 $k$**。从左到右扫，记 $prev$ 为前一首的最终值，当前歌取满足 $a_i^{2^k} \ge prev$ 的最小 $k$。最优性：当前歌只通过它留下的 $prev$ 影响后面所有歌，而后面的可行条件（值 $\ge prev$）关于 $prev$ 单调——$prev$ 越小后面越轻松。最小可行 $k$ 同时做到「本步代价最小」和「留下的 $prev$ 最小」，两者没有取舍，故贪心全局最优。
3. **唯一的无解情形**：$a_i = 1$ 且 $prev > 1$。1 平方多少次都是 1，永远追不上。

### 难点：爆炸值不进大数，取对数直接解出 $k$

平方几次之后数值是 $2^{2^{10^5}}$ 量级的塔——`long long`、`__int128` 都存不下。但**每个最终值都是「某个原值平方若干次」**，所以每首歌只需要记两个数：原值 $a_i$ 和它被平方的次数 $cnt_i$，最终值就是 $a_i^{2^{cnt_i}}$。

要让第 $i$ 首接住第 $i-1$ 首，条件两边取自然对数（两边都正，不等号不变向）：

$$a_i^{2^k}\ \ge\ a_{i-1}^{2^{cnt_{i-1}}}\iff 2^k\ln a_i\ \ge\ 2^{cnt_{i-1}}\ln a_{i-1}\iff k\ \ge\ cnt_{i-1}+\log_2\frac{\ln a_{i-1}}{\ln a_i}$$

右边是个已知实数、$k$ 又必须是整数，于是最小可行 $k$ **有闭式解**，一次搜索都不用做（可行集 $\{k:k\ge v\}$ 上闭，$\lceil v\rceil$ 就是它的最小值）：

$$k=\max\Big(0,\ \big\lceil cnt_{i-1}+\log_2\tfrac{\ln a_{i-1}}{\ln a_i}\big\rceil\Big)$$

- 塔高被压回可表示范围：要算的只是 $cnt_i+\log_2(\cdot)$，量级 $O(n)$，浮点轻松装下。
- 全程 $O(n)$：每首歌 3 次 `logl`，没有比较器、没有封顶、没有 while。

### 三个分支各挡两件事

闭式只在 $a_{i-1}>1$ 且 $a_i>1$ 时良定义，所以两个 `if` 同时是题意分支和数学分支：

- `a[i-1]==1` → `cnt[i]=0`：$prev=1$，谁都接得住，$k=0$；顺带挡住 $\ln 1=0$ 当真数（$\log_2 0=-\infty$，`(long long)(-∞)` 是 UB）。**必须写在 `a[i]==1` 之前**，否则 `[1,1]` 会被误判成 -1。
- `a[i]==1` → `return -1`：落到这里说明 $a_{i-1}>1$，即 $prev\ge2$，而 1 平方多少次都是 1；顺带挡住 $\ln 1=0$ 作除数（$x/0=\pm\infty$）。
- `else` → 闭式求 $k$，再 `if(k<0)k=0`：$a_i>a_{i-1}$ 时右边是负数（如 $a_{i-1}=2,a_i=10^6$ 给 $-4.32$），次数不能为负。
- 提前 `return -1` 不会串测试数据：**整个数组在进循环前就读完了**，输入流已停在下一个用例开头。

### 精度：`-1e-9` 容差的必要性与安全边界

闭式靠浮点，唯一的失效点是 `ceill` 跨越整数边界，两头都不能越：

**① 真值恰好是整数**——即 $\ln a_{i-1}/\ln a_i = 2^j$，也就是 $a_{i-1}=a_i^{2^j}$（$4=2^2$、$65536=2^{16}$、$10^6=1000^2$、$531441=729^2$）。这正是题里「取等也算可行」的边界用例。若浮点算成 $m+\varepsilon$，`ceill` 就多算一次演绎 → 答案偏大 → WA。**减掉 `1e-9` 把它拉回 $m$ 以下**，`ceill` 复原成 $m$。

**② 真值不是整数**——容差绝不能大到把 $\lceil m+\delta\rceil$ 从 $m+1$ 变成 $m$（漏一次演绎，序列真的不非递减，答案偏小）。安全边界是全域最小正间距 $\delta_{\min}$，实测：

| 扫描范围 | 用例数 | 最小非零 $\lvert L-\mathrm{round}(L)\rvert$ |
| --- | --- | --- |
| 全部 $p,q\le3000$ | $9\times10^6$ | $6.0\times10^{-5}$ |
| 近邻对 $p=q\pm1..6$，$q\le10^6$（已排除精确幂对） | $1.2\times10^7$ | $1.044\times10^{-7}$ @ $(999999,10^6)$ |
| 幂族 $p=q^{2^j}\pm3$，$q\le10^6$ | $\approx10^6$ | $1.044\times10^{-7}$ @ $(999999,1000)$ |

极小值来自相邻整数，可以解析估出：

$$\log_2\frac{\ln(q+1)}{\ln q}\approx\frac{1}{q\ln q\ln 2}\ \xrightarrow{\ q=10^6\ }\ 1.05\times10^{-7}$$

整数间隔是 1，没有别的构造能压得更低。**容差 $10^{-9}$ 比 $\delta_{\min}$ 小 104 倍**，两头都在安全区内。

- 这 100 倍余量是 $a_i\le10^6$ 买来的：上限若放宽到 $10^9$，$\delta_{\min}\sim10^{-10}$ 就会掉进容差里，必须重调。
- 最大 $cnt$ 出现在**严格递减序列**：每步 $\delta\sim10^{-7}$ 都是正小数，`ceill` 每步进 1 ⟹ $cnt$ 线性涨到 $n$（实测 $n=2\cdot10^5$ 时 $cnt_{\max}=199999$）。此时 $cnt+L$ 量级 $2\cdot10^5$，浮点绝对误差：80 位 `long double` 约 $2\times10^{-14}$；即便在 `long double == double` 的平台（MSVC、多数 ARM）也只有 $\mathrm{ulp}(2\cdot10^5)=5.7\times10^{-11}$，仍比 $\delta_{\min}$ 低 3 个数量级——**把 `logl` 全换成 `log` 后，15.7 万组用例 + 4 组 $cnt=2\cdot10^5$ 大数据零不一致**，这份代码可移植。
- 本机（g++ 16.1，`sizeof(long double)=16`，64 位尾数）实测 245 组精确幂探针的 $|raw-\text{exact}|$ **全为 0**：这台的 libm 把 $\ln 4/\ln 2$ 之类算得精确到整数，去掉 `-1e-9` 也零不一致。**容差在这台机器上是保险而不是补救**——但换个 libm 就可能必需，而它的代价是零。

### 贪心过程追踪（`3 2 2`）

| i | $a_i$ | $cnt_{i-1}$ | $v=cnt_{i-1}+\log_2\frac{\ln a_{i-1}}{\ln a_i}$ | $cnt_i=\lceil v-10^{-9}\rceil$ | 累计答案 |
| --- | --- | --- | --- | --- | --- |
| 1 | 3 | — | 首元素 | 0 | 0 |
| 2 | 2 | 0 | $\log_2\frac{\ln3}{\ln2}=\log_2 1.585=0.664$ | 1 | 1 |
| 3 | 2 | 1 | $1+\log_2\frac{\ln2}{\ln2}=1+0=1$（恰好整数） | 1 | 2 |

输出 2。第三行就是「取等可行」的样子：$\ln2/\ln2=1$、$\log_2 1=0$，$v$ 真值就是整数，`ceill` 不能被浮点上偏多推一格——这里 `-1e-9` 的位置正是它唯一的用武之地。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long solve(){
    int n; cin >> n;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    vector<long long> cnt(n, 0);   // cnt[i]：第 i 首被平方的次数
    long long w = 0;
    for (int i = 1; i < n; i++){
        if (a[i-1] == 1){
            cnt[i] = 0;            // prev=1 谁都接得住；同时避开 log(0)
        }
        else if (a[i] == 1){
            return -1;             // prev>1，1 追不上；同时避开除以 log(1)=0
        }
        else{
            // k = ceil( cnt[i-1] + log2(ln a[i-1] / ln a[i]) )，减 1e-9 抵消取等边界的上偏
            long long k = (long long)ceill(
                cnt[i-1] + logl(logl((long double)a[i-1]) / logl((long double)a[i])) / logl(2.0L) - 1e-9L);
            if (k < 0) k = 0;      // a[i] 比 a[i-1] 大时右边为负，次数不能为负
            cnt[i] = k;
        }
        w += cnt[i];
    }
    return w;                      // 数组已整体读入，中途 return -1 不会串测试数据
}

int main(){
    int t; cin >> t;
    while (t--) cout << solve() << '\n';
    return 0;
}
```

## 要点

- 可行集 $\{k: a_i^{2^k}\ge prev\}$ 关于 $k$ **上闭**（值随 $k$ 单调不降），所以最小 $k$ 就是 $\lceil v\rceil$，$v$ 是那串实数——这是「取上整」而非「试探搜索」的依据，闭式才不会漏最优。
- 每首歌的状态压成 $(a_i, cnt_i)$ 两个数，绝不去物化 $a_i^{2^{cnt_i}}$；比较一律搬到对数域 $cnt+\log_2(\cdot)$ 里做。
- `-1e-9L` 是**闭式解的命门**：取等边界（$a_{i-1}=a_i^{2^j}$）时 $v$ 是精确整数，浮点上偏一格 `ceill` 就多演绎一次。容差要卡在 $(10^{-10},\ \delta_{\min}=1.04\times10^{-7})$ 这个窗口里，`1e-9` 正好居中。
- `logl` 全程 `long double`：本题 $a_i\le10^6$、$cnt\le2\cdot10^5$，即便平台把 `long double` 退化成 `double`（MSVC/ARM）也够（实测零不一致）；但保持 `L` 后缀是零成本的保险。
- 两个 `if` 各挡「题意 + 数学」两件事：`a[i-1]==1` 给 $prev=1$ 的 $k=0$、并避开 $\log 0$；`a[i]==1` 给无解 -1、并避开除以 $\log 1=0$。缺一个就是 UB 或死判。
- `return -1` 早退安全的**前提是整个数组已读入**（`for(auto&x:a)cin>>x` 在循环外）；否则输入流停在半截，后面所有用例跟着错。
- 答案用 `long long`：$cnt$ 每步至多涨 5，但**严格递减序列**能让每步都涨、$cnt$ 线性顶到 $n$，最坏总次数 $\approx n^2/2$（实测 $200001..2$ 得 $1.99999\times10^{10}$），`int` 必溢。

## 坑

- **真存爆炸值**：$10^6$ 平方两次就是 $10^{24}$ 超 `int64`，全 2 长链是 $2^{2^{10^5}}$ 的塔，任何整数类型都装不下。必须在对数域比较——这也是本题区别于普通贪心的唯一难点。
- **`ceill` 不减 `1e-9`**：取等用例（$4=2^2$、$10^6=1000^2$、$65536=2^{16}$）真值是精确整数，浮点给 $m+10^{-16}$，`ceill` 变 $m+1$，多算一次 → WA。本机 libm 恰好算得准（245 组探针偏差全 0）不减也过，**但那是运气不是保证**，换编译器/libm 就翻车，`1e-9` 必须留。
- **容差过大（如 `1e-6`）**：会越过 $\delta_{\min}=1.04\times10^{-7}$，把「相邻整数本该 $+1$」误吸进下界，`ceil` 少算一次 → 序列其实没非递减。容差窗口是 $(10^{-10},1.04\times10^{-7})$，别乱调。
- **忘了 `if(k<0)k=0`**：$a_i>a_{i-1}$（升序段）时 $\log_2\frac{\ln a_{i-1}}{\ln a_i}<0$，$v$ 为负，`ceill` 给负数直接加进 $w$，总数被压低甚至变负。
- **两个 `if` 顺序反了**：先判 `a[i]==1` 再判 `a[i-1]==1`，会让 `[1,1]` 走进 `return -1`（把 $prev=1$ 的合法 1 误当无解）。必须 `a[i-1]==1` 在前。
- **`log` 用了 `int`/未转 `long double`**：`logl(a[i-1])/logl(a[i])` 里两操作数须是浮点；若写成整数除法或漏了 `(long double)` 强转，$\ln$ 的参数会先被截断，结果全错。
- **`a_i=1` 不单独判**：`logl(0)` 或 `x/logl(1)=x/0` 得 `±inf`/`nan`，`(long long)` 转换是 UB，程序不是输出 -1 而是给出垃圾甚至崩溃。

## 测试记录

**两套独立精确解做裁判**（都不依赖本文这份 `logl` 代码）：

- 裁判 A：整数封顶比较器 $x^{2^k}\ge b^{2^e}$（底数 $\le10^6$ 时精确跑贪心），先用 Python 大整数对 20 万组随机 $(x,k,b,e)$ 交叉验证，封顶比较与大整数**零不一致**，确认 A 是真值。

| 245 组「精确幂」探针 $\lvert raw-\text{exact}\rvert$ | 全为 0（本机 libm 取整边界算得精确） |
| 去掉 `-1e-9` | 本机零不一致（保险未触发）；换 libm 不保证，故正文保留 |
| `logl`→`log`（`long double`→`double`，模拟 MSVC/ARM） | 157,498 组 + 4 组 $cnt=2\cdot10^5$ 零不一致 |
| 近邻对 $\delta_{\min}$ 实测 | $1.044\times10^{-7}$（$(999999,10^6)$），容差 $10^{-9}$ 留足 104 倍余量 |
