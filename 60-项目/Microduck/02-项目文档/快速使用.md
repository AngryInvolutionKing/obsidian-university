# Microduck 快速使用

本机已经配置好 Python 依赖和官方上游仓库。

## 桌面使用中心

所有快捷入口、分类教程和文件说明集中在：

[`C:\Users\zhang\Desktop\Microduck 使用中心`](file:///C:/Users/zhang/Desktop/Microduck%20%E4%BD%BF%E7%94%A8%E4%B8%AD%E5%BF%83)

先打开其中的 `00-从这里开始.md`。

## 双击使用

- 双击 [`Microduck.cmd`](file:///C:/Users/zhang/Desktop/Microduck%20%E4%BD%BF%E7%94%A8%E4%B8%AD%E5%BF%83/08-%E9%A1%B9%E7%9B%AE%E4%BB%93%E5%BA%93/microduck-replica/Microduck.cmd)：打开统一菜单。
- 桌面 `Microduck 控制台`：打开统一菜单。
- 桌面 `Microduck STL 查看器`：直接打开本地 STL 查看器。

## 终端调用

在任意 PowerShell 或 CMD 窗口中执行：

```powershell
microduck
microduck view
microduck status
microduck docs
microduck debug
microduck hardware
microduck render
microduck export
microduck holes
```

完整参数：

```powershell
microduck help
```
