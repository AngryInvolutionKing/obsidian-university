## 可替换的 MATLAB 骨架

下面骨架使用控制系统对象生成与 Simulink 同口径的单位阶跃检查。它不是完成的作业：`num1`、`den1`、`num2`、`den2` 必须先按讲义中的两条传递函数替换，当前空数组会让断言失败。每一次改动参数后都要重新运行并把图文件名填入 Excel；最终 `.slx` 仍是原题要求的交付物。

```matlab
% 从 10.PID.pdf 原样填写系数；不要由 README 残缺文本猜测。
num1 = [];  den1 = [];
num2 = [];  den2 = [];

assert(~isempty(num1) && ~isempty(den1));
assert(~isempty(num2) && ~isempty(den2));

stopTime = 50;
Kp = 0;  Ki = 0;  Kd = 0;       % 每一行 Excel 对应一组独立参数

G1 = tf(num1, den1);
C1 = pid(Kp, Ki, Kd);
T1 = feedback(C1 * G1, 1);      % 单位负反馈
[y1, t1] = step(T1, stopTime);
info1 = stepinfo(y1, t1, 1);

figure(1); clf;
plot(t1, y1, 'LineWidth', 1.2); grid on;
title('G1 PID step response');
xlabel('time (s)'); ylabel('output');
exportgraphics(gcf, 'G1_Kp0_Ki0_Kd0.png');

G2 = tf(num2, den2);
C2 = pid(Kp, Ki, Kd);
T2 = feedback(C2 * G2, 1);
[y2, t2] = step(T2, stopTime);
info2 = stepinfo(y2, t2, 1);
```

`tf` 把讲义中的分子、分母系数变成连续传递函数；`pid` 保存一组 PID 增益；`feedback(C*G,1)` 明确构造单位负反馈，避免在模型图中把正负号接反；`step` 产生单位阶跃响应；`stepinfo` 只是在给定参考值 $1$ 下汇总响应特征，不能替代目视检查波形。`exportgraphics` 生成可追溯的图片文件。若本机没有 MATLAB、Control System Toolbox 或相关授权，骨架不能运行，不能把代码文本当作完成了仿真。

## Simulink 结构与参数记录

每个对象至少使用 `Step → Sum → PID Controller → Transfer Fcn → Scope` 的闭环结构，并把输出回接到 `Sum` 的负输入。`Step` 提供一致的参考输入，`PID Controller` 写入当行 $K_p,K_i,K_d$，`Transfer Fcn` 写讲义原始分子/分母，`Scope` 用于核对瞬态和稳态，`To Workspace` 或导出图片用于归档。停止时间上限为 $50$ 秒；若系统在此前明显发散，也保留该失败行及图，不要仅保存稳定结果。

建议 Excel 每行固定写模型编号、$K_p,K_i,K_d$、仿真停止时间、阶跃幅值、上升时间、峰值时间、超调量、稳态观察、响应图路径和备注。先建立 $K_i=K_d=0$ 的比例基线，再一次只改变一个增益；每次比较使用同一传递函数、同一阶跃幅值、同一反馈符号和同一停止时间。调参顺序是教学建议而非讲义已经验证的最优策略，不能据此先断言某组参数最优。

## 控制流程、常见错误与最小自检

流程是抄录讲义传递函数→核对分子/分母与系统编号→搭建负反馈模型→运行基线→只改一个参数并保存曲线→把参数和图写入同一行→重复另一条传递函数→检查 Excel 与图片一一对应。这里没有 MCU HAL API、外设寄存器、引脚或电平条件；若以后把同一参数用于电机，采样周期、输出限幅、编码器单位和真实对象模型都要重新核验，不能把 Simulink 参数直接写进固件。

常见错误包括把两条传递函数混用、分子和分母位置颠倒、`Sum` 块接成正反馈、改了多个增益却只记一个、每张图使用不同的停止时间、只截 Scope 不保存参数、把不稳定响应删除、用连续模型的增益直接宣称实体电机安全。最小自检是逐字符对照讲义公式；每一行都能从模型参数回到图片；比例基线、一次只改一个增益的步骤和失败尝试均有记录；输出最终收敛时再比对 `stepinfo` 与 Scope，二者不一致时先检查模型连接和参考值。
