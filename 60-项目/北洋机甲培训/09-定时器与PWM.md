什么是时钟？什么是时钟树？
时钟是单片机的脉搏，是系统工作的同步节拍。每跳动一下，整个单片机的各个电路就同步的动作
一下时钟信号是周期性的脉冲信号。在芯片内部是各种的逻辑门电路，如果不统一时序，会导致不同
门电路的运算之间出现延迟，进而导致后续的寄存器出差，程序出错。所以有一个同步的信号就显得
十分重要。 同时STM32有很多外设器件，每个器件的时钟信号不一样，所以要将一个固定的信号频率
进行倍频/分频处理，达到每个外设需要的频率。时钟信号的分频就像树的分支一样，这就是时钟树。
•
什么是时钟频率？
指的是处理器或其他数字电路每秒钟振荡的次数，单位是赫兹（Hz），通常以 MHz（兆赫， Hz）
来表示。例如，时钟频率为 1 GHz 的CPU，每秒钟振荡 10亿次。时钟频率直接决定了处理器执行指令
的基本速度，但并不是唯一影响性能的因素。

在比较模式下，预装载寄存器的内容被复制到影子寄存器中，然后影子寄存器的内容和计数器进行比

3、PWM
1）什么是PWM
脉冲宽度调制(PWM)，是英文“Pulse Width Modulation”的缩写，简称脉宽调制，可以理解为
控制脉冲的宽度，利用微处理器的数字输出来对模拟电路进行控制的一种非常有效的技术，它通过控
制信号的脉冲宽度，实现对电压或电流的精确控制。在嵌入式的应用中，如果数字信号控制的LED只有
完全亮与灭两种状态，怎么能实现控制亮度大小呢？这就用到了PWM等效输出模拟量。
2）PWM的相关参数
PWM主要有三个参数：频率、占空比、分辨率
•
频率（Frequency）：是指1秒钟内信号从高电平到低电平再回到高电平的次数(一个周期)，也就是
说一秒钟PWM有多少个周期。
•
占空比（Duty Cycle）：是一个脉冲周期内，高电平的时间与整个周期时间的比例，占空比决定了
PWM等效出来的模拟电压的大小，占空比越大，模拟电压越趋近于高电平。
•
分辨率（Resolution）：就是占空比变化的快慢，占空比变化的细腻程度。占空比跳的快如按照
1%跳变与按照0.1%跳变，那么0.1%的跳变就越细腻，越柔和。
频率 = 1 / TS
占空比 = TON / TS
分辨率 = 占空比变化步距
利用PWM调节LED亮度，就是让LED不断地点亮、熄灭、点亮、熄灭...，当这个点亮熄灭的频率足够大
时，LED就不会闪烁了，而是呈现出一个中等的亮度。调控点亮、熄灭的比例时，就能让LED呈现出不
同的亮度级别。这也是PWM的基本思想。
3）定时器怎么输出波形
•
第一步：CNT（计数器）与CCR（捕获比较寄存器）（上述定时器的内容中有提到） ，如果CNT大
于or等于CCR，就会给输出模式控制器传一个信号；
•
第二步：输出模式控制器就会改变它输出OC1REF的高低电平，REF信号实际上就是信号的高低电
平（REF:reference，参考信号）；
•
第三步：CC1P：极性选择寄存器，给0，信号就会走对应的0那一路，信号不变；给1，信号会经过
一个非门，极性翻转；
•
第四步：信号从OC1输出。
4)PWM的基本结构和计算公式
PWM频率： Freq = CK_PSC / (PSC + 1) / (ARR + 1)  （ CK_PSC见前文 ）
PWM占空比： Duty = CCR / (ARR + 1)
PWM基本原理比较好理解，更重要的是理解怎么产生的，然后实质还是要理解定时器的原理

三、相应HAL库函数介绍
1、定时器基本模式启动函数HAL_TIM_Base_Start
全写：HAL_StatusTypeDef HAL_TIM_Base_Start(TIM_HandleTypeDef *htim);
功能： 用于启动定时器基本模式
运行流程： 当使用了HAL_TIM_Base_Start函数后，定时器将开始计数，并在达到预设的计数值时就
会重新开始计数
2、定时器基本模式中断启动函数HAL_TIM_Base_Start_IT
全写： HAL_StatusTypeDef HAL_TIM_Base_Start_IT(TIM_HandleTypeDef *htim);
功能： 用于启动定时器的基本模式并使能定时器中断
运行流程： 就是当使用这个功能来启动定时器的时候，和上面的定时器基本模式启动函数不同 的是，
开始计数后，在达到预设的计数值时会触发中断，进入中断处理函数，在中断处理函数中根据不同的
中断源来选择回调函数，在回调函数中进一步处理
3、定时器周期到达回调函数HAL_TIM_PeriodElapsedCallback
全写： void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim);
功能： 定时器中断的回调函数。
运行流程： 当中断源是定时器周期到达的情况下，在中断处理函数中会据此进入到定时器周期到达回
调函数（这个函数HAL_TIM_PeriodElapsedCallback）中进行进一步的操作
4、定时器中断处理函数HAL_TIM_IRQHandler
全写：void HAL_TIM_IRQHandler(TIM_HandleTypeDef *htim)
功能： 此功能处理TIMx全局中断
运行流程： 进入中断处理函数，在中断处理函数中根据不同的中断源来选择回调函数
5、开启编码器模式HAL_TIM_Encoder_Start;
全写：HAL_TIM_Encoder_Start(&htim2, TIM_CHANNEL_ALL);
功能：开启定时器的编码器模式
🥛运行流程： 进入中断处理函数，在中断处理函数中根据不同的中断源来选择回调函数
首先在CubeMx中配置好之后，前面写的初始化函数就自动配置好了，可以不用管
然后在main.c文件中使用 HAL_TIM_Base_Start或者HAL_TIM_Base_Start_IT 来启动定时器

如果是使用 HAL_TIM_Base_Start 那就去调用计数值这类数值去分析
如果是使用 HAL_TIM_Base_Start_IT 那就去编写 HAL_TIM_PeriodElapsedCallback 在这个

提示：
// 电机转过一圈产生的脉冲数计算：
// 电机的基础脉冲 * 电机的减速比 *4
// 解析：电机基础脉冲为电机一转产生的脉冲数
// 而电机的减速比则会让电机内部转若干圈，电机外部才会转过一圈，
// 所以实际上电机外部转过一圈产生的脉冲数为  电机的基础脉冲 * 电机的减速比
// 而代码用的是 __HAL_TIM_GET_COUNTER，
// 在 STM32 的编码器模式下，定时器默认会对 A、B 两相的上升沿和下降沿都计数（即 4倍频）。
// 查阅产品手册可得，减速比为90， 电机基础脉冲为 11
constexpr float ENCODER_COUNT = 11 * 90 * 4; //电机转过一圈产生的脉冲数

constexpr float DT = 0.001f;//控制周期dt为1ms
constexpr float PI = 3.1415926535f;

// 编码器结构体定义
typedef struct
{
TIM_HandleTypeDef tim;
int32_t count;
float radps;
bool direction;
}encoder;

// 速度获取函数
void get_speed(encoder* encoder)
{
encoder->count = __HAL_TIM_GET_COUNTER(&encoder->tim);

if (encoder->count >= 32768)
{
//说明是向反向旋转
encoder->count -= 65536;
}
encoder->direction = __HAL_TIM_IS_TIM_COUNTING_DOWN(&encoder->tim);

//速度计算
encoder->radps = (float)encoder->count / ENCODER_COUNT * 2 * PI / DT;  // 电机
的角速度，单位：rad/s

__HAL_TIM_SET_COUNTER(&encoder->tim, 0);

}

六、思考题
1. 已知 STM32 通用定时器 TIM3 挂载于 APB1 总线，系统配置 APB1 预分频系数为 2（即
PCLK1=36MHz），因此 TIM3 的时钟 TIMxCLK=72MHz。若需让 TIM3 每 500ms 触发一次中断，
需配置预分频器 PSC 和自动重装载寄存器 ARR 的值（假设不考虑其他因素）：
◦请根据文档中的定时时间公式（Timeout = ((PSC+1)×(ARR+1))/TIMxCLK），计算 PSC 和
ARR 的一组合理值（要求 PSC 和 ARR 均为 16 位以内整数）；
◦解释公式中 “PSC+1” 和 “ARR+1” 的原因，并说明若省略 “+1” 会导致定时时间产生何种
偏差。
2. 请设计基于 STM32CubeMX 和 HAL 库的 “LED 1 秒频闪” 功能（定时器中断实现），梳理完整配
置流程，需包含以下关键步骤：
◦时钟树配置：如何选择时钟源（如 HSE）并将系统主频配置为 72MHz，TIMx 时钟如何推导；
◦定时器参数配置：选择哪个定时器（如 TIM2），PSC、ARR 的值如何设定（需匹配 1 秒定
时）；
3. 文档中提到 L298N 电机驱动模块可通过 “单PWM+双IO口” 控制电机，若需实现以下功能，请分
别列出 IN1、IN2和PWM口的电平 / PWM 状态：
◦电机 A 正转且调速；
◦电机 A 反转且调速；
