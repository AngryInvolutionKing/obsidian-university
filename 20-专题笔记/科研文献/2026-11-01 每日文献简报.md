# 每日文献简报（2026-11-01）

今日速览共推荐 2 篇新论文，均与 LLM Agent 相关。

## 1. LLM Agent-Based Design of RISC-V CPUs with FPGA-in-the-Loop Evaluation

- **期刊/来源**：arXiv（预印本）
- **发表时间**：2026-10-29
- **DOI**：原文未明确报告（原文标注“DOI未核验”）
- **值得看的一句话**：这篇论文把 LLM Agent 的 CPU 设计流程放在 FPGA 上做在板性能评估，报告显示同一候选设计运行 8,000 次 CoreMark 时，FPGA 评估（含实现）比单线程 RTL 仿真快 9.6 倍，而且发现了一种在短期诊断运行中表现改善、但在长时间运行中出现性能退化的候选设计。
- **链接**：http://arxiv.org/abs/2610.39570v1

## 2. InterA11y: Interactive Web Accessibility Error Detection with LLM Agents

- **期刊/来源**：arXiv（预印本）
- **发表时间**：2026-10-29
- **DOI**：原文未明确报告（原文标注“DOI未核验”）
- **值得看的一句话**：这篇论文提出用评分标准和交互工具支持 LLM Agent 检测网页无障碍错误，在 197 个专家标注案例上，召回率为 79.0%，高于最强 LLM 基线 44.4%，精确率为 93.1%，与最佳规则检查器相当。
- **链接**：http://arxiv.org/abs/2610.39488v1
