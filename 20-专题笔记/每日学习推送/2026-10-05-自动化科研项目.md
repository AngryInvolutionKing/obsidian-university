# 2026-10-05 自动化科研项目：小车路径跟踪与前视距离研究

今天推荐 [AtsushiSakai/PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics)。它提供机器人算法的 Python 示例，建议范围限定为“小车路径跟踪中的前视距离选择”，先做仿真。

具体入口是 [PathTracking/pure_pursuit/pure_pursuit.py](https://github.com/AtsushiSakai/PythonRobotics/blob/master/PathTracking/pure_pursuit/pure_pursuit.py)。Pure Pursuit（纯追踪）根据前方目标点决定转向；这份示例还用比例控制调节速度。虽然文件开头写了 PID，实际的 proportional_control 只有 Kp * (target - current)，所以这里应称速度 P 控制。

## 与自动化的联系与本科生范围

参考路径、车辆状态、控制输入和运动模型连成闭环。你可以观察小车为何偏离路径、转向为何来回变化、速度为何影响跟踪，对应误差反馈、参数调节与性能评价，也能为电机速度环和移动机器人学习打基础。

大二版本完成原算法复现、参数扫描、误差统计与解释。大三版本再提出考虑速度与路径弯曲程度的前视距离规则，并通过公平对照检验效果。可行性判断基于这个缩小后的范围。

需要 Python 基础、向量与距离、三角函数和基本反馈控制概念。这个示例直接使用 NumPy 与 Matplotlib。第一阶段普通电脑即可，无需 STM32 或实体小车；完整仓库其他模块的依赖可能更多，配置应遵循仓库当时的安装说明。本次核验了源码，没有执行 Python 仿真。

## 一个可检验的研究问题

在不同车速与弯道条件下，前视距离规则如何影响跟踪误差与转向平滑性？

原源码已经使用 $L_f=kv+L_{fc}$，所以“随速度变化的前视距离”是仓库已有做法。可以比较固定距离、原始速度规则、自己设计的速度与曲率联合规则。第三种只是候选方案，收益需要实验支持。

各方法采用相同参考路径、初始状态、运动模型、时间步长、目标速度与转向限幅。先在独立调参路径上调整参数，再在直线、缓弯、急弯与 S 弯上评价；若加入噪声，使用同一组扰动与随机种子，并重复多次。

记录横向误差均方根、最大误差、转向变化幅度、完成率与实际速度。统一误差算法，例如车辆后轴中心到参考折线的最短距离；不能把到前视目标点的距离当作横向误差。未完成路径的情况单独报告。

## 路线与验收

预计 4–6 周完成仿真阶段，取决于 Python 与控制基础。第一周跑通示例并解释状态更新；第二周保存轨迹和控制量，实现统一评价；第三周扫描原规则参数；第四周实现候选规则并做同条件比较；第五、六周加入初始偏差或噪声，整理代码与报告。

验收成果包括可复现代码、参数配置、轨迹与误差图、指标表，以及解释优势和失效条件的短报告。复现与候选改进都可构成本科科研训练；是否有可发表的新意，需要进一步文献核验与实验结果。
