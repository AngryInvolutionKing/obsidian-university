## 怎么用

**读**：在 Copilot 里直接给路径，例如

```
读 C:\Users\zhang\Desktop\数学\数学资料\Ch1.1集合与映射(4).pdf
```

agent 会走本机 `miyo-parse`（Miyo 自带 CLI）或 `pdfread` —— 两者都接受任意绝对路径，**不要求文件在库内、也不要求先进索引**。

**搜**：Miyo 已把该目录注册为索引文件夹（递归），新文件会被索引；要立刻生效可以手动触发一次扫描：

```powershell
curl.exe -s -X POST http://127.0.0.1:8742/v0/scan -H "Content-Type: application/json" -d '{\"path\":\"C:\\Users\\zhang\\Desktop\\数学\",\"force\":false}'
```

**扫描件**：纯图片的 PDF 没有文字层，需要 OCR 才有可读正文：

```powershell
pdfread ocr "<pdf 绝对路径>" --lang chi_sim+eng --dpi 300 --pages 1-120 --out "<pdf>.ocr.md"
```

生成的 `.ocr.md` 放在 PDF 旁边，`md` 也在 Miyo 的索引扩展名里，所以顺带变成可搜索的。

## 边界

- **只有库内文件**才能用 `[[` 引用、拖进聊天输入框、加入项目上下文；**库外文件**一律靠"报绝对路径"。
- 外部目录里的文件**不要复制进库**（除非我自己要求）；也不要为了读一个路径外的文件而要求我先把文件搬进库。
