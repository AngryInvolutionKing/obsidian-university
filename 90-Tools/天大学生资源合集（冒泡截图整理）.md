## 三、GitHub Student Developer Pack（学生包）申请流程

- 前置：**TJU 教育邮箱**（形如 `学号@tju.edu.cn`）。**正确入口是 `candle.tju.edu.cn`（天津大学邮箱注册）**，或从 `mail.tju.edu.cn`（天津大学邮件系统）点「注册」跳转。
  - 注册流程（官方《邮箱注册帮助手册》）：打开 candle → 点「登录」→ 自动跳转**天津大学校园统一认证系统**（学生用户名 = 学号；新生可点「激活账户」，忘记密码可「找回密码」）→ 填**邮箱登录名 + 关联手机号 + 初始密码** → 阅读并同意《天津大学邮箱管理规定》→ 点「申请」→ **两个工作日内**系统自动审核通过即可使用
  - 邮箱命名规则（信网中心 FAQ）：只能小写字母 / 数字 / 下划线，长度 3–18 位，不能以数字或 `_` 开头，**不能与学号相同**
  - 帮助手册 PDF：<https://candle.tju.edu.cn/public/static/file/2019082701.pdf>（实测 200，594 KB，7 页）
  - 服务页 / FAQ / 迎新网说明：<https://its.tju.edu.cn/xfw/qbfw/dzyx.htm> ｜ <https://its.tju.edu.cn/info/1295/1179.htm> ｜ <https://yx.tju.edu.cn/itianda/dzyxkt/>
  - ⚠️ 网上流传的教程（包括这次截图里那份）给的是 `wxjlx.tju.edu.cn/cn/life/email-account` —— 该**域名已无 A 记录**（阿里 DNS `223.5.5.5`、Cloudflare `1.1.1.1`、天大自家 DNS `202.113.2.1` 全部解析不出），所以打不开不是网络或权限问题，是这条链接本身失效了。
- 步骤：GitHub 绑定该邮箱并验证 → Profile 用**真实姓名**、Public email 设成 `@tju.edu.cn` → Billing 填真实地址（示例：Peiyangyuan Campus, No.135 Yaguan Road / Haihe Education Park / Tianjin / 300000）→ `github.com/settings/billing/payment_information` 里 **Start an application** → 选 **Student** → 点 **Share Location** 时**必须允许浏览器定位且不能开 VPN**（截图里有反面案例：`Denied on November 20, 2025`，理由就是定位不可用）→ 上传**带日期的学生证**照片 → 通过后 **72 小时**权益到账（JetBrains 全家桶、Copilot 等）
- ⚠️ **截图里那条"手写一张伪造的学生证上传"的做法不要学。** 那属于伪造证明材料，违反 GitHub 服务条款，被查出来会直接拒审甚至封号；用自己真实的学生证 / 在读证明 / 学信网截图就好。
