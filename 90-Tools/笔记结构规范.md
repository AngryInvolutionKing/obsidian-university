# 笔记结构规范

本库笔记的组织规范。**写新笔记、拆旧笔记、做结构整理时一律照此执行。**

- 库根 `AGENTS.md` 的「笔记结构」一节只写硬规则并指向本文件；
- Copilot 提示词（`copilot/copilot-custom-prompts/`）同样指向本文件。
- 规则只在这里维护一份，改规则改这里。

---

## 一、三层结构

```
课程主页（课程名.md）        ← 只做课程级入口：课程信息、笔记链接、作业、复习清单
  └── 讲次页 / 章主页（NN-*.md）  ← 只做索引：本讲速览、子页导航、复习清单、疑问
        └── 子页（NN.M-*.md）        ← 只放正文：定义、定理、证明、例题、方法
```

| 层级 | 只负责 | 不负责 |
|---|---|---|
| 课程主页 | 课程信息、讲次入口、作业清单、课程级疑问 | 任何一节的具体正文、逐条复习清单 |
| 讲次页 / 章主页 | 本讲速览、子页导航、复习清单、疑问、课件原件 | 大段定义与证明 |
| 子页 | 一个主题的定义、证明、例题 | 索引职责 |

**判断口诀**：打开一篇笔记，如果它的目录里同时出现「导航条目」和「正文标题」，就该拆。

---

## 二、硬规则

1. **一篇一个主题。** 一篇子页只回答一个问题。出现两条互不依赖的证明主线，就拆。
2. **理论不进作业页，作业不进理论页。**
   - 作业解答页只放：题目、解答、必要的引用（用 `[[理论页#标题]]` 链过去）。
   - 作业页若要引用某个定理，只写「见 [[某页#某定理]]」，**不复制定理的完整表述与证明**。
3. **同一结论只有一个详细版本。** 某个定理/推论/反例的完整证明与反例，只在它的归属页展开一次。其他页写「见 [[归属页#标题]]」＋本题怎样用它。
   - 归属：定义与定理进理论页；「本题怎么用」进作业页。
4. **拆分必须同步索引。** 拆完立刻检查三处，缺一不可：
   - 课程主页的「笔记链接」／「本周内容」；
   - 讲次页/章主页的「本讲索引」「目录」；
   - 所有指向被拆页的 `[[...]]` 与 `[[...#锚点]]`。
5. **节号沿用原编号。** 拆分时**不要重排号**。原第 1–7 节留在原讲次页，第 8–12 节进新页，新页仍叫「8.」「9.」……
   - 理由：`[[页#8. 待定型与 Stolz 定理]]` 这类锚点链接靠标题文字工作，重排号会静默断链。
   - 新页在开头写一句「本页承接 [[原页]] 的第 8–12 节（节号沿用原编号）」。
6. **改名必须全库更新入链。** 文件重命名后，全库 `grep` 旧名，把所有 `[[旧名]]`、`[[旧名|别名]]`、`[[旧名#锚点]]` 换成新名。改完再 `grep` 一次旧名确认归零。
7. **导航只在讲次页出现一次。** 子页不写自己的小目录列表（会与讲次页重复）；子页只写「关联课程主页」「本页承接/续篇」和「关联笔记」。

---

## 三、什么时候该拆

按去空白正文字符（含公式源码）计：

| 信号 | 阈值 | 动作 |
|---|---|---|
| 篇幅 | > 8 000 | 考虑拆 |
| 篇幅 | > 15 000 | 必须拆 |
| 二级标题数量 | > 12 | 考虑拆 |
| 二级标题数量 | > 20 | 必须拆 |
| 混排 | 作业题与理论混在一页 | 立即归位 |
| 标题覆盖 | 正文有内容在标题里找不到 | 补标题或拆出 |

**拆的边界按概念依赖切，不按行数切。** 例如「线性组合与生成子空间」应切成：线性组合 → 线性相关/无关 → 极大无关组·等价·秩 → 基与维数。引理与紧随其后的推论要留在同一页，保住证明链。

**不该拆的**：围绕一个证明目标展开的长推导（例如「e 是无理数」）；同一问题的例题详解。长不是理由，**主题多**才是。

## 四、拆分操作规程

复制这份清单逐条打勾：

1. **列出标题行号**：`grep -n '^#'` 目标文件，确定每节的起止行。
2. **定归属**：写下「哪几节留原页 / 哪几节进哪个新页」，按概念依赖检查一遍。
3. **按行区间切片**（脚本切片，不要手抄公式）。每节连同它的 `###` 子标题一起搬走。
4. **补新页头部**：frontmatter（四键）＋一级标题＋`- 关联课程主页：[[课程名]]`＋一句「本页是 [[原页]] 的拆分部分，承接第 X–Y 节（节号沿用原编号）」。
5. **补新页尾部**：`## 关联笔记`，至少链回原页、上游页、下一篇。
6. **重写原页**：原页降级为讲次页/索引页，保留「本讲速览」「目录→子页导航」「复习清单」「疑问」「课件原件」。
7. **改写锚点**：原页里指向已迁出节的 `[[#锚点]]` 要变成 `[[新页#锚点]]`。
8. **全库更新入链**：把所有指向原页的锚点链接改指新页。
9. **跑 §二.4 的三处索引检查。**
10. **校对**：新页标题数 = 原页迁出标题数；无断链；frontmatter 四键齐全。

## 五、frontmatter

固定四键，顺序不变：

```
---
type: 课堂笔记
course: 课程名
tags: [课程/数学分析, 状态/已整理]
created: 
---
```

- `type`：`课堂笔记` / `习题解答` / `课程主页` / `索引` / `规范`。
- `tags` 用斜杠分层：`课程/xxx`、`专题/xxx`、`类型/习题`、`状态/待整理|已整理`。
- `created` 一律留空（课程主页可填真实建库日期），**绝不猜日期**。
- 旧格式（`课程:`、`章节:`、`讲义日期:` 缩进列表）一律换成上面四键；原信息若要保留，写进正文的引用块。

## 六、命名

| 对象 | 形式 | 例 |
|---|---|---|
| 课程主页 | `<课程名>.md` | `数学分析（新工科）I.md` |
| 讲次页 | `NN-<主题>.md` | `07-数列的收敛准则与无理数e.md` |
| 章主页 | `NN-<章名>.md` | `02-线性方程组.md` |
| 子页 | `NN.M-<主题>.md` | `02.3-线性组合与生成子空间.md` |
| 作业页 | `NN-<主题>-习题X-Y.md` | `07-数列的收敛准则-习题2-4.md` |
| 例题页 | `NN-<主题>-例题与习题.md` | `07-数列的收敛准则-例题与习题.md` |

同一门课内部保持一致；两种布局（平铺 / 分文件夹）都可用，不强制统一。

## 七、状态与「疑问」写法

- 状态只有一个来源，写清楚是哪种：**已核对**（与讲义/课件逐条对过）、**部分解决**、**待补**。不要在一处写「完整证明链」而在另一处写「第 ⑤ 步待补」。
- 「疑问」逐条写**哪里不确定**，不要写「看不懂」。
- 目录里不留死入口：目录列出的每个 `[[#标题]]` 都必须在正文里存在。**目录改完必须回头验一遍。**

---

## 八、每次改动后的自检

```
1. grep 旧文件名 → 应为 0 命中
2. 所有 [[#锚点]] 的目标标题在本页存在
3. 课程主页「笔记链接」包含全部讲次页
4. 讲次页「本讲索引/目录」包含全部子页
5. frontmatter 四键齐全，tags 用斜杠分层
```
