# 回校可用资源与待办（天大校园网）

> 第一版：2026-10-07 白天，校外网络下逐条实测。
> 第二版：2026-10-07 晚，**人在校内、出口在校园网**时复测，新增第七、八节；第八节是把信网中心「全部服务」逐个点开抄下来的服务地图（含服务对象，能直接判断"我能不能用"）。
> 正版软件/Office 激活这条**已按用户要求跳过**，只在第七节留一行事实备查。

## 结论先行

1. **「回校才能下文献」不成立**：图书馆数据库校内外都统一走电子资源访问平台，VPN 也不再代理公网学术库；今晚实测还确认——**校内 IP 也不自动放行，仍要统一认证登录**。
2. 真正只在校内才有意义的：**校内信息系统 + 实验室器材 + 线下服务**。
3. **今晚最该抓紧的是一件有窗口期的事**：`VPN 用户激活` 和 `统一身份认证(TjuKey) 激活` **只能在校园网内做**，VPN 又**只能在校外使用**。人现在在校 → 现在激活，回家/出差才用得上。

## 二、真·只有回校才有的

1. **校内信息系统**：教务 `e.tju.edu.cn`、财务、一卡通、图书馆借阅、学院服务器。
2. **社团/实验室器材**：示波器、直流电源、焊台、热风枪，以及**社团的 STM32F103ZET6 系统板**。单片机、烧录器、蓝牙模块都能到实验室借，但**只能在实验室用**。
   → 手上只有 ST-Link、没有板子，那条 `init mode failed` 就该在这里收口：用社团板子试一次，立刻分清是**板子/接线**问题还是**调试器**问题。
3. **图书馆实体**：借教材（C++、数据结构、STM32）、研究厢/研讨间、考试季自习座位。
4. **体育场馆**：预约入口是**微信公众号「天津大学场馆服务」**（不是网页）：关注 → 菜单「个人中心」→ 本校师生选「学号/工资号登录」→ 选场次；动态看订阅号「天津大学场馆中心」（服务号每月只能群发 4 条）；体育部电话 022-27403611。
5. **就业活动**：`job.tju.edu.cn`，10 月是秋招旺季，低年级去听纯赚信息差。
6. **线下办事**：教务处/学院（成绩单、学籍证明）、校医院、一卡通、批量打印。

## 五、实测小坑（抓网页的人必踩）

- **信网中心服务页有两层壳**：`its.tju.edu.cn/xfw/qbfw/<页>.htm` 只是 **1KB 的 Visual SiteBuilder 跳转壳**，正文在 `<目录>/<文件>.htm`，而且**文件名不总等于目录名**：`Carsi/Carsi.htm`、`eduroam/eduroam.htm`、`vpn/VPNfw.htm`、`dzyx/dzyx.htm`、`sjk_/sjkfw.htm`、`cc_/ccfw.htm`、`tiandyp/tdyp.htm`、`yzj/yzj.htm`、`tyshenrz/tysfrz.htm`。静态抓取必须跟随壳里那个隐藏 `<a href>`，否则永远只能拿到标题。
- **图书馆主页是 JS 门户**：`home.lib.tju.edu.cn` 是 2481 字节 Vue/layui 空壳，静态抓不到正文；图书馆微信推文也全被 captcha 拦。

## 七、2026-10-07 晚 · 校内实测复核

### 1. 网络身份：出口确实在校园网，但链路是「手机热点」

| 项 | 实测值 |
| --- | --- |
| 无线 SSID | `vivo X300`（**手机热点**，WPA2-Personal，信号 99%） |
| 本机地址 | `10.78.249.213`，网关 `10.78.249.126` |
| 附近无线扫描 | 只扫到 `vivo X300` 一个 SSID |
| **真实公网出口**（`curl --noproxy "*"`） | **`202.113.185.29`**；ipip 报「中国 天津 天津 **教育网**」，ipinfo 报 `AS4538 China Education and Research Network Center` |
| 电子资源平台看到的来源 | `您的IP：172.18.58.67`（校内私网段） |

**结论**：物理在校 + 出口在 CERNET，说明手机上游接的是校园网、笔记本再经热点 NAT 出去，校方看到的源地址落在**校内网段**，所以校内 IP 类资源通得过。两个副作用：① **热点一断就不再是校内 IP**；② 多一层 NAT，`curl` 往返 0.2–1.0 s。想稳就直连 `tjuwlan`（账号=学工号，密码=校园网密码，忘了走 `g.tju.edu.cn`）或宿舍有线 PPPoE。

### 2. 电子资源平台：校内 IP ≠ 免登录

- `eds.tju.edu.cn` → 302 → `/ermsClient/home.do` → 302 → `/ermsClient/browse.do` → 200
- 点「登录」跳到 → `https://user.lib.tju.edu.cn/#/login?client_id=uni40x176f9a18ac3&redirect_uri=https%3A%2F%2Feds.tju.edu.cn%2FermsLogin%2FSSOLoginResult.do&response_type=code`，标题「**天津大学图书馆用户统一认证平台**」
- 平台原话：「本馆电子资源对持证读者免费开放，读者可以通过到馆查阅或馆外远程访问电子资源。」

→ 校内也得统一认证登录；这正是"校内外统一走平台"的现场证据。

### 3. 软件下载平台（仅作事实备查，不推进激活）

`kms.tju.edu.cn` 实为「天津大学软件下载平台」，在架 Windows 11/10、Windows Server 2019、Office 2024/2021、WPS 365、麒麟；激活说明为：麒麟开机自动激活、WPS 365 用统一身份认证激活、微软产品下载 `GP4` 程序。实测 `http://kms.tju.edu.cn/uploadfile/iso/iso-qita/GP4.exe` 返回 200 / 8,204,608 字节（免登录可下）；`kms.tju.edu.cn:1688` 端口不通（不靠直连 KMS）。**结论：平台对学生开放，但按用户要求不搞激活，此条到此为止。**

### 5. 探测方法上的两个坑

1. 本机跑着 FlClash，**环境变量有大小写两套** `HTTP_PROXY`/`http_proxy`（另有 `ALL_PROXY`、`NO_PROXY`、`NODE_USE_ENV_PROXY=1`）——PS 5.1 的 `Get-ChildItem env:` 会因重复键抛「已添加了具有相同键的项」，得用 `cmd /c "set | findstr /i proxy"`。
2. 这台机器的 `pwsh` 工具实际落到 **Windows PowerShell 5.1**：没有 `-NoProxy`。要绕代理直连就用 `curl.exe --noproxy "*"`，状态码用 `-w '%{http_code}'`。
