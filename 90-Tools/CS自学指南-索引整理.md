## 三、给你的路线（嵌入式 / C++ 方向）

| 顺序 | 课程 | 为什么排这里 |
|---|---|---|
| 0 | MIT-Missing-Semester（必学工具：Shell/Vim/Git/CMake） | 你已在用 Git+Gitee、CLion、CMake，这门课把工具链的坑一次补齐 |
| 1 | Stanford **CS106L**（Standard C++ Programming） | 正经讲 C++ 本身：RAII、模板、STL、移动语义，比「能编译就行」高一层 |
| 2 | CMU **15-213 CSAPP**（计算机系统基础） | 指针/内存/汇编/链接/并发，解释你在 STM32 上的链接脚本、启动文件、栈与堆 |
| 3 | UCB **CS61C** 或 **Nand2Tetris**（体系结构） | 从逻辑门到流水线到 RISC-V，硬件与软件的接口 |
| 4 | MIT **6.S081 / 6.1810**（操作系统） | 内核视角，对裸机与 RTOS 的理解帮助最大 |
| 5 | UCB **EE16A/B** + MIT **6.003**（电子基础/信号与系统） | 电路、采样、傅里叶：传感器、电机、舵机、电赛的理论底子 |
