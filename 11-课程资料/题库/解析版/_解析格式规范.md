# 题库解析格式规范（Agent 执行标准）

> 本文件是所有「题库解析」子任务的统一标准。执行任务的 agent 必须先读本文件，产出与本规范完全一致的格式。解析笔记存放：马原 / 毛概 / 思修放在 `11-课程资料\题库\解析版\`；习概 21 份已于 2026-10-01 移至课程目录 `10-课程笔记\习近平新时代中国特色社会主义思想概论\题库解析\`（wikilink 按笔记名解析，移动不影响既有链接）。

## 通用硬规则（违反任何一条即为不合格）

1. **题目原文逐字保留**：题干、选项从源题库文件逐字复制（含错别字、缺字、多余标点），不改写、不"修正"、不删减。选项保持原有换行方式。
2. **不遗漏任何一题**：源题库共 N 题，输出必须恰好 N 题，题号顺序与源文件完全一致。完成后自查：输出文件中 `**数字.**` 开头的题目行数 = N。
3. **引文绝不编造**：凡标注为教材「原文」的引文，必须逐字来自指定教材 markdown 文件（可用 grep 定位后复制）。找不到就写「未找到直接对应原文」，不许凭记忆编造、不许改字、不许拼接改变原意。
4. **解析面向考试**：说明正确项为什么成立、错误项的陷阱、易混点、记忆钩子。写实质内容，禁止空话套话（如"本题考查了重要知识点，需要认真掌握"）。每题解析 2–4 句。
5. **文件过长分多次写入**：先 Write 写入前半部分，再用 Edit 在文件末尾锚定追加后半部分（oldString 用文件当前结尾的唯一句子）。
6. 输出为 UTF-8 编码的 `.md` 文件。frontmatter 中的 `源题库` 用 `"[[笔记名]]"`（带引号）。

## A 类：习概（教材 OCR 在库内，每题必须配原文引用与双链）

教材原文位于 `11-课程资料\习近平新时代中国特色社会主义思想概论\教材全文（OCR）\`（`00_导论.md` ～ `17_第十七章_全面从严治党.md`，另有 `00_全书_合并.md`）。Obsidian 的 `[[...]]` 链接自动形成双向链接（反链），因此解析笔记里指向教材章节标题的链接就是题目↔教材的双链。

# <源题库笔记名> · 解析

> 基于 [[<源题库笔记名>]] 逐题解析，教材原文逐字引自 [[<教材OCR笔记名>]]（2023年版）。
> 配套精读：[[<精读章笔记名>]]。共 N 题（单选 a / 多选 b / 判断 c）。

## 一、单选题

**1.** <题干原文>
A. xxx B. xxx
C. xxx D. xxx
**答案：C**
- 解析：<2–4 句>
- 原文："……<教材逐字摘录，≤80 字，省略处用……>……"（[[<教材OCR笔记名>#<二级或三级标题原文>|第X章·标题短名]]）

## 二、多选题
（同格式）
```

### A 类细则

- **标题锚点**：先用 grep 在教材文件里列出 `^#{1,4} ` 标题，`[[文件#标题]]` 的锚点文字必须与教材标题逐字一致（含"第一节""一、"等编号前缀，不含 `#` 号本身）。
- **章节练习题**（习思想教材配套练习题 各章）：只引用该章对应的教材 OCR 文件；文件头「配套精读」链到 `10-课程笔记` 下对应精读章笔记（如 `[[04-坚持以人民为中心]]`）。
- **汇总题库**（习概单选题汇总 / 习概多选题汇总，题目跨全书）：用 grep 在教材 OCR 文件夹内检索题干关键词，找到所属章节文件后引用，链接指向具体章文件（不是合并版），形如 `[[04_第四章_坚持以人民为中心#第二节 坚持人民至上|第四章·坚持人民至上]]`。
- **判断题**：同样给「答案：正确/错误」，解析指出错误点在哪，原文行照常。
- **源题库缺答案的题**（没有 `**答案：**` 行）：自己判断答案，写成 `**答案：X（原题未给，据教材判定）**`，解析中给出判定依据。
- **找不到原文的题**（题干考的是教材之外的时政细节，或 OCR 缺字）：原文行写 `- 原文：未找到直接对应原文；相近内容见 [[<教材OCR笔记名>#<标题>|章·节]]。` 尽量给"相近内容"链接，不许硬编造引文。
- OCR 文本可能有断行、`<!--p.NN-->` 页码注释、`==高亮==` 标记、`[[...]]` 内链（如 `[[十个明确]]`）。摘录引文时：去掉 `<!--p.NN-->` 注释与换行拼接成连续文字，保留 `==` 内的文字但去掉 `==` 本身；如果教材里引文本身含 `[[十个明确]]` 这类双链，摘录时写成「十个明确」纯文字，避免输出文件产生意外的嵌套链接歧义（链接目标写在括号内的正式链接处）。

## B 类：马原 / 毛概 / 思修（教材原文不在库内）

这三门课的教材原文没有入库，**不得编造教材引文**。每题只做解析 + 知识点定位，并在文件头统一说明。

# <源题库笔记名> · 解析（第X部分：第 a–b 题）

> 基于 [[<源题库笔记名>]] 逐题解析。本课程教材原文未入库，无法配教材双链；解析依据通行教材（马工程《马克思主义基本原理》（2023年版）/《毛泽东思想和中国特色社会主义理论体系概论》（2023年版）/《思想道德与法治》（2023年版））的知识体系撰写。

**1.** <题干原文>
A. xxx
B. xxx
**参考答案：C**
- 解析：<2–4 句>
- 知识点：<模块定位，如「唯物论·物质与意识」「毛概·第二章 新民主主义革命理论」「思修·人生观」>
```

### B 类细则

- **答案来源**：
  - 马原两份题库每题自带 `**参考答案：X**` → 原样保留；个别缺失的自己判定并标「（原题未给，判定）」。
  - 毛概两份题库答案在每章末尾的答案串里（如 `**参考答案：CAADB ACC**`）→ 按题目顺序逐题解码回填到每题下方，写 `**答案：C（据章末答案串）**`。答案串字数与题目数不符时，按顺序尽量对应，无法确定的题标 `**答案：？（答案串对不上，据知识判定为 X）**`。
  - 思修例题答案内嵌在题干括号里（如 `说明（D）（重点）`）→ 题干原样保留（含括号内答案），不再另加答案行，解析里说明为什么是 D；多选的「（多选）」标记同理保留。
  - 思修单选题 / 思修选择题题库（带答案）：自带答案的原样保留，缺失的自己判定并标注「（原题未给，判定）」。
- **知识点标签体系**：马原按「马克思主义哲学（唯物论/辩证法/认识论/唯物史观）、政治经济学、科学社会主义」+ 细分主题；毛概按教材章名；思修按「人生观、理想信念、中国精神、社会主义核心价值观、道德、法治」等模块。
- 毛概题若与习概教材高度重合（新时代部分），可在知识点行追加 `相关：[[<习概教材OCR章>|习概·第X章]]`，形成跨课程双链。
