## 演示代码怎么用

文件夹里按主题分组，直接按你当天课上的进度找对应文件跑：

- 基础语法与流程：`Welcome.cpp`、`TestBoolean.cpp`、`TestBreak.cpp`、`TestDo.cpp`
- 数组与字符串：`TestArray.cpp`、`ReverseArray.cpp`、`ArrayPointer.cpp`、`CompareString.cpp`
- 函数与引用：`TestPassByValue.cpp`、`TestPassByReference.cpp`、`DefaultArgumentDemo.cpp`
- 类与对象：`Circle.cpp`、`Date.cpp`、`Student.cpp`、`CopyConstructorDemo.cpp`
- 继承与多态：`GeometricObject.cpp`、`DerivedCircle.cpp`、`WhyPolymorphismDemo.cpp`
- 模板与 STL：`GenericStack.h`、`TestVector.cpp`、`TestList.cpp`、`TestSet.cpp`、`TestPriorityQueue.cpp`
- 异常与文件：`ExceptionDemo1.cpp`、`SimpleFileInput.cpp`、`BinaryIODemo.cpp`
- 算法练习：`SortDemo.cpp`、`BinarySearch.cpp`、`TowersOfHanoi.cpp`、`Sudoku.cpp`

`.exe` 和 `.gch` 是编译产物，不用看，只读 `.cpp` 和 `.h`。

## 仓库版课程经验（供参考）

期末闭卷两小时，英文试卷，题型是选择、填空、手写程序；成绩构成是平时作业 + 上机题 + 期末。仓库作者的结论是「以自学为主，有基础的同学没难度，没基础的要课下多练；上机题偏难，考试反而比较基础」。这条和多数 C++ 课的经验一致：难点在上机，期末靠基础。

## 用法

1. 每周：把课上讲到的语法点对应的演示代码找出来跑通，再自己改一处逻辑重编。
2. 上机前：先看对应主题的演示代码，再写自己的。
3. 期末前：模拟题 00、01 限时手写（不借助编译器），手写程序是主要失分点。
4. 长期：有余力就按仓库建议刷 ACM 入门题，对后面数据结构有帮助。

## 注意

- 教师不同，仓库版英文卷和考核比例不一定适用于喻梅老师的班。
- 演示代码是 Visual Studio 工程，里面有 `.sln`、`.vcproj`、`.tds` 等工程文件，用编辑器直接开 `.cpp` 即可。
- 仓库没有这套课的历年真题，只有两份模拟题和演示代码。
